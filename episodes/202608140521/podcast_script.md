### トピック1: DeepSeek、フラッグシップ「V4 Pro 0813」がプレビューを卒業しGA

📅 2026年8月12〜13日公開（出典: Unite.AI／Simon Willison's Weblog／TechTimes）

DeepSeekがフラッグシップモデル **DeepSeek-V4-Pro-0813** を一般提供（GA）に移行しました。**総パラメータ1.6兆、トークンあたりアクティブ490億**のMoE構成で、**コンテキスト100万トークン（1,048,576）**・**最大出力38.4万トークン**に対応します。

### トピック2: Astro 7.2、実験的「インクリメンタル静的ビルド」でページ再生成をスキップ

📅 2026年8月6日公開（出典: Astro公式ブログ／パッチ版7.2.1は8月11日）

Astro 7.2の目玉は実験機能 **incremental static builds**。数千ページ規模のドキュメントサイトやブログでは、変更が数ページでも毎回全静的ページを再レンダリングしていました。この機能はその**生成フェーズ**を差分化します。

有効化は `experimental.incrementalBuild: true`。ルート側は `getStaticPaths()` が各パスに **`cacheKey`** を返してオプトインします（コンテンツコレクションなら `entry.digest` が適任）。Astroはビルド時に**テンプレート・レイアウト・コンポーネント・インポート資産まで含むモジュールグラフ全体をハッシュ化**し、**モジュールハッシュとcacheKeyの両方が前回と一致したページだけ再利用**します。**cacheKeyのないパスは常に再生成**されるため、既存プロジェクトの挙動は変わりません。キャッシュは `cacheDir`（既定 `node_modules/.astro/`）に置かれ、CIでの永続化がそのまま効きます。

このほか **`session: false`** でセッションランタイムをバンドルから除去（ドライバ未設定なら自動でtree-shake）、**`astro preview --background`** とstatus/logs/stopサブコマンド、`logger.entrypoint` の相対パス指定にも対応しました。

### 🔒 トピック3: Microsoft 8月のPatch Tuesday、悪用済みゼロデイ含む400件規模を修正

📅 2026年8月11日公開（出典: Tenable／SecurityWeek／BleepingComputer／Qualys）

修正件数はベンダーの集計方法により **398〜421件**と幅がありますが、**約400件規模**で、うち**62件がCritical**。**ゼロデイは3件（2件が公表済み、1件が実環境で悪用中）**です。

悪用が確認されているのは **CVE-2026-68820** — Windows Ancillary Function Driver for WinSock（AFD.sys）の**use-after-free**による権限昇格で、**CISAが同8月11日にKEVカタログへ追加**しました。ほかCVSS 9.8のRCEとして **CVE-2026-62815（Microsoft QUIC）**、**CVE-2026-62893（Windows展開サービス）**、CVSS 9.6の情報漏えい **CVE-2026-56161（Azure Logic Apps）** が含まれます。

### 🔒 トピック4: Metabaseに**CVSS 10.0**の未認証SQLインジェクション、悪用進行中で修正期限は本日

📅 2026年8月6日アドバイザリ公開／8月11日KEV追加（出典: Metabase GitHub Advisory／The Hacker News／Wiz／Bishop Fox）

オープンソースBIツールMetabaseに、**満点のCVSS 10.0**である **CVE-2026-72898** が公開されました。影響範囲は **0.58/1.58 〜 0.63.4系**。

原因は**未認証で到達可能な `POST /api/session/reset_password`** が**リクエストボディの未宣言フィールドを制限していなかった**こと。想定外の値が**検証済み識別子ではなく構造化入力としてアプリDBのユーザー検索に到達**します。**認証もユーザー操作も不要**、ネットワーク越しに低い攻撃複雑度で成立し、成功すれば**管理者権限の奪取 → 設定変更・接続先DBの認証情報窃取・データエクスポート**まで可能です。

Metabaseは**実環境での悪用を確認済み**。**CISAは連邦機関に本日8月14日を期限として修正適用を指示**しています。即時アップグレードが難しい場合は、**`/api/session/reset_password` エンドポイントの一時遮断**が回避策として案内されています。
