### トピック1: Anthropic、プルリクエスト支援の「Claude Ship」をベータ公開
📅 2026年11月24日公開（出典: gihyo.jp）

Anthropicが**11月23日**、GitHubのプルリクエスト（PR）作業を支援する **Claude Ship** をベータ公開しました。

- **Code Review**（一般提供済み）: PRの問題点をコメント
- **PR Steward**（ベータ）: レビュー指摘・**CIの失敗・マージ衝突を自動修正**。プッシュごとに変更内容と戻し方のメモを残す
- **Claude Approvals**（ベータ）: リポジトリの承認ポリシーを読み、条件を満たす変更は**Claudeが承認**。ブランチ保護の必須チェックにも設定可能（github.comのみ）

対象は**Team／Enterpriseプラン**で、Code ReviewとPR Stewardはトークン使用量に応じた課金（組織ごとに月額上限を設定可）。ゼロデータ保持などの設定の組織では利用不可です。Claude Code CLI／デスクトップには、コミットからPR作成までを行う **`/ship` コマンド**も順次展開されています。

### トピック2: State of HTML 2026の結果が公開
📅 2026年11月18日掲載（出典: Frontend Focus #767）

HTMLの利用実態を調べる開発者調査 **State of HTML 2026** の結果が公開されました（調査期間10/1〜11/1、回答者約2,100人）。

- 利用率トップは **`details`/`summary`（72.5%）**、次いで **`dialog`（67.8%）**
- **Popover APIの利用率が40%**に到達
- **`select`と日付入力のスタイリング**が依然として最大の悩み。カスタマイズ可能なselectはFirefox未対応が足かせ
- `datalist`の利用は30%→44%に増えた一方、好意的評価は44%→34%に低下
- 欲しい機能1位は**ソート・フィルタ付きのネイティブデータテーブル**（タブ、コンボボックス、スイッチが続く）

総括では、不満の矛先が**仕様からブラウザ（特にモバイルOS）の対応遅れへ**移りつつあると指摘されています。※数値はニュースレターの要約に基づきます。

### 💻 トピック3: PowerShell 7が次期Windowsに標準搭載へ
📅 2026年11月19日公開（出典: gihyo.jp、Microsoftの発表は11月17日）

Microsoftが、**PowerShell 7を次期Windowsに標準搭載**すると発表しました。同日、**Windows PowerShell 5.1は非推奨**に。

- 次期Windowsでは5.1が**オンデマンド機能（FoD）**扱いに。ただし新規インストールでは既定で有効、**セキュリティ更新は継続**
- 将来の削除時期は未定（事前告知予定）。Windows 11 26H2など既存版では7は引き続き別途インストール
- 起動名は **5.1が`powershell.exe`、7が`pwsh.exe`**。`powershell.exe`を呼ぶタスクは7搭載後も5.1で動作
- MSIX版`pwsh.exe`はSYSTEM権限のタスクから起動できない、`Add-WindowsCapability`など一部DISMコマンドレットが動かない等の制限があり、修正中

**推奨アクション**: 5.1を呼んでいるタスク・サービスを洗い出し、**スクリプトをPowerShell 7でテスト**、新規の自動化は7で書くこと。
