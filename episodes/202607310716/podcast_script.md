### トピック1: JetBrains、AIエージェント向け「JetBrains Context」を発表
📅 2026年7月31日公開（出典: Publickey）

JetBrainsが、コードリポジトリの上に**インテリジェンスなレイヤ**を構築し、AIエージェントに適切なコード・コンテキストを提供する新サービス「**JetBrains Context**」を発表しました。

Claude CodeやOpenAI Codexなどのエージェントは、正しいコードを書くためにリポジトリを何度も検索・読み込みします。JetBrains Contextは**事前構築したコードインデックス**と**セマンティック検索**を提供し、この往復を削減。**マルチリポジトリ対応**により、API利用や依存関係、影響範囲まで広い文脈を渡せます。

同社の計測では、**エージェントのターン数が最大68%削減**、**レイテンシ最大59%削減**、**実行コスト最大48%削減**。現在は「JetBrains AI for Teams and Organizations」利用者向けの**アーリーアクセス**として提供中です。

### トピック2: Chrome 151安定版リリース、textStream()や\<usermedia\>要素を追加
📅 2026年7月29日公開（出典: GIGAZINE / Chrome for Developers）

Chrome 151の安定版が公開され、開発者にとって実用的なAPIが複数追加されました。

- **textStream() メソッド**: Request / Response / Blob に追加。従来 `response.body.pipeThrough(new TextDecoderStream())` と書いていた処理が `response.textStream()` で済み、**パイプのつなぎ忘れというよくあるミスを防止**できます。
- **\<usermedia\> 要素**: `getUserMedia()` の呼び出しに代わり、メディアストリームの開始を**HTMLで宣言的に記述**。許可要求がユーザーの意図と明確に紐づきます。
- **Declarative Shadow DOM**: `<template>` に `shadowrootslotassignment` 属性が追加され、**手動スロット割り当てを宣言的に**書けるように。
- **soft-navigation / interaction-contentful-paint**: Performance APIに新しいPerformanceEntryが追加。**SPAでもルート遷移ごとに正しく性能を計測**できます。
- **Manifest V2 拡張機能が完全に無効化**されました。

次の安定版Chrome 152は2026年8月25日リリース予定です。

### 🔒 トピック3: Ruby on Railsに深刻な脆弱性 CVE-2026-66066（CVSS 9.5）
📅 2026年7月29日公開（出典: The Hacker News）

Ruby on Railsが、Active Storageの**クリティカルな脆弱性**に対する修正をリリースしました。細工した画像アップロードを通じて、**未認証の攻撃者がサーバー上の任意のファイルを読み取れる**というものです。

漏洩しうる情報には **secret_key_base、Railsマスターキー、DBパスワード、クラウドストレージ認証情報、APIトークン**が含まれ、そこから**RCE（リモートコード実行）や横展開**に発展するおそれがあります。

影響を受けるのは、Active Storageの画像処理に**libvips**を使い、信頼できないユーザーからの画像アップロードを受け付けるアプリケーション。対象範囲は **Rails 7.0.0〜7.2.3.1 / 8.0.0〜8.0.5 / 8.1.0〜8.1.3**（Rails 6系はVips設定時のみ）。`load_defaults 7.0` 以降はVipsが既定選択となる点に注意が必要です。

### 🔒 トピック4: AIエージェント基盤「Ruflo」に最大深刻度の脆弱性 CVE-2026-59726（CVSS 10.0）
📅 2026年7月29日公開（出典: The Hacker News）

Claude Code / OpenAI Codex向けのオープンソース・エージェントメタハーネス「**Ruflo**」（旧Claude Flow、GitHub 66,500スター超）に、**CVSS 10.0の未認証リモートコード実行**の脆弱性が報告されました。Noma Labsによる通称は「**RufRoot**」です。

原因は、**シェルコマンド実行・DB操作・エージェント管理・メモリ保存を含む233個のツール**が、**認証なしのMCPブリッジ経由でデフォルトでネットワークに公開**されていたこと。これにより攻撃者は任意コマンドの実行に加え、**AIのメモリを汚染（ポイズニング）**することも可能でした。

**3.16.3より前のすべてのバージョン**が影響を受けます。

## まとめ

本日は、AIエージェントにコード文脈を効率よく渡す**JetBrains Context**、開発者向けAPIが充実した**Chrome 151**、そして**Rails**と**Ruflo**という、WebとAIそれぞれの土台に空いた深刻な穴をお届けしました。

エージェントが触れる範囲が広がるほど、**その足元にある権限設定とデフォルト構成の見直し**が効いてきます。特にRufloのケースは「デフォルトで開いている」ことがそのまま致命傷になった例です。お使いのフレームワークとツールのバージョン、今日のうちに確認しておきましょう。
