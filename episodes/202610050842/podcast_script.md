### トピック1: Cloudflare、文章ではなく「確率」で答える意思決定モデル「Clef」を公開
📅 2026年10月1日公開（出典: Cloudflare Blog、MarkTechPost、gihyo.jp）

Cloudflareが **意思決定モデル（Decision model）「Clef」と「Clef-flash」** をオープンウェイトで公開しました。LLMのように文章をトークンごとに生成するのではなく、**決まった形式の質問に対して全選択肢の確率を1回の順伝播で返す** のが特徴です。

- 質問形式は3種類: **yes/no**、**選択（choice）**、**ルーブリック採点（score）**
- 入力はテキスト・JSON・画像・動画。Workers AIでは1リクエスト最大64問・画像4枚、コンテキスト65,536トークン
- パラメータ: **Clef 27B／Clef-flash 9B**
- レイテンシ中央値（ベンダー公表値）: **Clef 209ms／Clef-flash 39ms**
- 分類系ベンチマーク（BANKING77、CLINC150）では汎用LLMを上回る一方、GPQAなど知識系では及ばない
- Workers AI料金: 入力100万トークンあたり **Clef $0.24／Clef-flash $0.09**
- ライセンスは **Apache 2.0**、Hugging Faceからセルフホストも可能。強化学習による微調整サービスも発表

分類・ルーティング・エージェントの分岐判断など、**「文章は要らず判断だけ欲しい」処理の高速化・低コスト化** に効きそうです。

### トピック2: 自然言語とコード検証を混在できるE2Eテストフレームワーク「e2e」がOSS化
📅 2026年10月2日公開（出典: gihyo.jp）

TesterArmyが、AIエージェントを使う **エンドツーエンド（E2E）テストフレームワーク「e2e」** をオープンソースで公開しました。

- **自然言語の指示と、従来のロケーター／アサーションによる厳密な検証を同一テスト内で併用** できる
- Webは **Playwright経由**、**iOS／Androidのモバイルアプリも共通API** で扱える
- 検証済みの操作を **キャッシュ** し、次回実行を効率化
- 複数のAIプロバイダーやローカルモデルを選択可能、独自エージェント実装にも対応
- コードを書かずにAIがアプリを操作する **探索テスト機能** も搭載
- TypeScript製、**Node.js 22.12以上**（WindowsはWSL推奨）、ライセンスは **Apache-2.0**
- 導入は `npx e2e init` で対話形式

### 🔒 トピック3: FortiMailに認証不要の任意ファイル書き込みゼロデイ、悪用を確認
📅 2026年10月2日公開（出典: The Hacker News）

フォーティネットのメールセキュリティ製品 **FortiMail** に、**CVE-2026-104286（CVSS 9.8）** が公表されました。

- 原因は **パストラバーサル** と **NUL文字の不適切な処理**
- **認証不要** の攻撃者が、細工したHTTP/HTTPSリクエストで **任意のファイルを書き込み可能**
- **実際の攻撃での悪用を確認**、CISAがKEVカタログに追加（連邦機関の対応期限は10月4日）
- 影響: 8.0.0〜8.0.1、7.6.0〜7.6.6、7.4.0〜7.4.8、7.2.0〜7.2.9
- 修正版: **8.0.2／7.6.7／7.4.9以降**（7.2系は7.4系への移行推奨）
- 緩和策: IBE機能の無効化、**管理インターフェースへのインターネットからのアクセス制限**

### 🔒 トピック4: ヘルプデスクOSS「Zammad」の脆弱性連鎖、数秒でroot奪取の悪用例
📅 2026年10月2日公開（出典: Security Affairs）

オープンソースのヘルプデスクシステム **Zammad** の脆弱性2件が、CISAのKEVカタログに追加されました。

- **CVE-2026-102489（CVSS 9.4）**: **セッション固定** によるセッションハイジャックで、`zammad`ユーザーとしてのリモートコード実行が可能。影響は6.3.0〜6.5.4、7.0.0〜7.1.3
- **CVE-2026-102490（CVSS 9.4）**: **不適切な権限管理** により、`zammad`ユーザーから **root権限へ昇格** 可能
- 2件を **連鎖させた攻撃が実際に確認** されており、初期アクセスからroot取得まで **数秒** との報告も
- 連邦機関の対応期限は10月5日。セルフホスト運用者は **最新の修正版への即時更新** を推奨
