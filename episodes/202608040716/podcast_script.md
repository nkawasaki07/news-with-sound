### トピック1: MCPの新仕様が公開、通信がステートレス方式へ
📅 2026年7月27日公開（出典: Publickey）

AIエージェントと外部ツールをつなぐ規格 **MCP（Model Context Protocol）** の新仕様が **2026-07-28版** として公開されました。

最大の変更点は **通信のステートレス化** です。従来は接続ごとに `Mcp-Session-Id` ヘッダでセッションを管理するステートフルな通信でしたが、新仕様では **initialize によるハンドシェイクとセッションIDへの依存が廃止**。各リクエストが必要なプロトコル情報・クライアント情報を自分で持つ **自己完結型** になります。

サーバーの水平スケールや運用は楽になる一方、**新旧は通信形式そのものが噛み合わず双方向に非互換**です。TypeScript SDK も **9パッケージに分割され、すべて v2.0.0 として公開**されました。既存のMCPサーバー運用者は移行計画が必須です。なお **GitHubは公開に先立ち7月23日に対応を表明**しています。

### トピック2: Rust製フルスタックWebフレームワーク「Topcoat」登場
📅 2026年7月29日公開（出典: CodeZine／原発表は Tokio ブログ 7月22日）

Rustの非同期フレームワーク **Tokio** の開発チームが、フルスタックのリアクティブWebアプリを構築するフレームワーク **「Topcoat」** を発表しました。

- **サーバーレンダリング方式**：サーバー側でHTMLスニペットをレンダリングし、「リアクティブ命令」をメタデータとして付与してリアクティビティを実現
- **WebAssemblyを使わない**：マクロにより、**完全に型チェックされたRust式のサブセットをJavaScriptにクロスコンパイル**
- クライアントの状態変化のたびにサーバーでUI全体を再レンダリングし、**必要な部分だけ差し替える**構成も可能
- **Topcoat UI** は shadcn/ui にインスパイアされた Tailwind ベースのコンポーネント集。`topcoat ui` CLIで**プロジェクトにコピーされる**ため自由に改変できる

開発チームは「AIコーディングエージェントが使える今、**構築時間の差は言語ではなく利用可能なライブラリ群で決まる**」と指摘。ORMの Toasty に続く布石で、今回が**最初のリリース**、今後は Toasty との緊密な連携がロードマップに入っています。

### 🛠 トピック3: Kubernetes v1.37 の Sneak Peek 公開
📅 2026年7月31日公開（出典: Kubernetes公式ブログ）

次期 **Kubernetes v1.37** の事前告知記事が公開されました。Sneak Peek は、**非推奨・削除・置き換えが予定される変更を正式リリース前に周知する**ための記事です。

- **正式リリース予定日: 2026年8月26日**
- 機能凍結（Enhancements Freeze）は6月16日、コード凍結は7月22日に完了済み
- 周辺の技術メディア報道によれば、注目点は **DRA（動的リソース割り当て）の拡充**（GPUを論理分割して個別にPodへ割り当てる Partitionable Devices など）、**containerd 2.0 / cgroup v2 への移行**、**セキュリティ既定値の引き締め**

※ 記事自身が明記するとおり、**内容は正式リリースまでに変更される可能性**があります。クラスタ運用者は、アップグレード前に削除予定機能の確認を。

### 🛠 トピック4: GitHub Actions、悪質なワークフローを自動保留
📅 2026年7月30日公開（出典: CodeZine／GitHub発表は7月28日・現地時間）

GitHubが **サプライチェーン攻撃対策**として、GitHub Actions の悪質なワークフローを**自動で保留する**新機能を発表しました。

- 背景: **流出したGitHub認証情報**を使い、公開リポジトリへ不正ワークフローをプッシュして **CI/CD認証情報を窃取**する攻撃が増加
- 挙動: 悪質と判定された実行は**即時に開始されず**、**書き込み権限を持つコラボレーターのレビューと承認**が必要。承認は**認証済みウェブセッション経由**で行う
- 適用: **ユーザー側の設定は不要**で、github.com 上の公開リポジトリに自動適用
- 注意: **GitHub Enterprise Server には現時点で未適用**

## まとめ

本日は、AIエージェント基盤・Web・インフラの三方向で「土台の作り替え」が並びました。**MCPはステートレス化**でスケールしやすい方向へ舵を切り、その代償として**非互換な移行作業**が発生します。Web側では **Tokioチームが WebAssembly を経由しない**という独自解で Rust のフルスタック領域に踏み込みました。インフラでは **Kubernetes v1.37 が8月26日のリリースに向けて輪郭を現し**、**GitHubはCI/CDを狙う攻撃に自動防御**で応じています。

仕様変更と防御強化のどちらも、足元の環境を点検するきっかけになりそうです。
