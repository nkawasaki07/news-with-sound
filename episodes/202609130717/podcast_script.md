### トピック1: Sakana AI、「Fugu Max」「Fugu Ultra v2」を同時リリース
📅 2026年9月11日公開（出典: Sakana AI公式 / TECH NOISY）

東京拠点のSakana AIが、**複数モデルを束ねるマルチエージェント統合モデル**を2種類同時公開しました。

- **Fugu Max**（コスト効率優先）: 入力 **$2 / 出力 $6**（100万トークンあたり）で、競合フロンティアモデル比 **40〜60%安**。6つのベンチマークで最高スコアを記録
- **Fugu Ultra v2**（性能優先）: Chartography **48.3**、DeepSWE **74.3**
- いずれも **OpenAI互換API** で提供

核になっているのは、**タスクの難易度に応じて専門モデルを自動で振り分ける「モデルルーティング」**です。難問は高性能モデル、単純作業は安価なモデルへ振り分けることでコストと精度を両立させます。特定のプロプライエタリモデルに依存しない設計のため、**API料金改定や規約変更のリスクを分散したい場合の選択肢**になります。

### トピック2: 古いCSSをモダンな書き方に置き換える無料ツール「Modern CSS Radar」
📅 2026年9月10日公開（出典: コリス / DUB DESiGN）

**公開ページのURLを入れるだけで、ブラウザ標準機能に置き換えられる自前実装を洗い出す**オンラインツールです。

- スキャナは **Chromiumで実際にページを描画**し、最後までスクロール、コントロールへのホバー、安全に試せるクリックまで実行して証拠を収集
- **27のチェック項目**＋18のコード・挙動パターン＋9のCSS改善。対象例は `<dialog>` / popover、`:has()`、`<details>`、`@starting-style`、`animation-timeline` など
- 指摘ごとに**根拠となるコードとブラウザ対応状況**が付き、出荷前チェックリストやPDFレポートも生成
- **無料、1人1日10回まで**

ただし**サーバーサイドのコード、認証後の状態、隠れた業務ロジックは対象外**。あくまで公開ページ範囲の棚卸しツールとして使うのが適切です。

### 💻 トピック3: .NET 11 Release Candidate 1 登場 ― C# 15の「Union（共用体）」とランタイムネイティブ async
📅 2026年9月8日公開（出典: .NET Blog / Publickey 9月11日報道）

**Go-Liveライセンス付き**のRC1が公開されました。正式版は **2026年11月**予定です。

- **C# 15で「Union（共用体）」と「閉じた階層」を新設**。「複数の型のうちどれか1つ」という状態を、継承やobject型を使った回りくどい書き方なしに型として表現できる
- **ランタイムネイティブ async（Runtime Async V2）**: コンパイラ生成のステートマシンを、**ランタイム自身が中断・再開を管理する方式**へ置き換え。**スタックトレースが読みやすくなり、オーバーヘッドも低下**。net11.0 ターゲットなら `EnablePreviewFeatures=true` は不要に
- **Native AOT が runtime-async コードのコンパイルに対応**。単一ファイルプログラム向けの Native AOT キャッシュも追加
- **利用可能なプロセッサ数の上限を撤廃**

### 💻 トピック4: NVIDIA、RustでGPUカーネルを直接書く「CUDA Rust」を発表
📅 2026年9月8日公開（出典: NVIDIA Technical Blog / MarkTechPost）

**他言語のラッパーではなく、RustのコードがそのままGPUカーネルになる**仕組みが2トラックで提供されます。

- **cuda-oxide**: Rust の MIR から Pliron・LLVM を経由して **PTX** を生成する SIMT カーネル。現状は**早期アルファ**
- **cutile-rs**: **CUDA Tile IR** を通して JIT コンパイルする Tile カーネル。**stable Rust 1.89 以降**で動作し、すでに HuggingFace の Grout や mistral.rs で社外採用実績あり

最大の利点は、**Rustの所有権システムによってメモリのエイリアスに起因するバグを実行時ではなくコンパイル時に検出できる**こと。AIのシステム層がRustで書かれる比率が高まっている状況を受けた動きで、NVIDIAは2027年以降もCUDA Rustを育てていくとしています。
