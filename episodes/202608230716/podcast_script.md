### トピック1: Slack Code 公開 — AIコーディングエージェントをチームチャンネルへ
📅 2026年8月20日公開（出典: Salesforce / VentureBeat / Dataconomy）

Salesforce傘下のSlackが **Slack Code** を発表。**Claude Code（Anthropic）、Devin（Cognition）、GitHub Copilot、Vercel Agent** を Slack のチャンネル内で直接動かせる。

- 会話中でエージェントにメンションすると、**タスク専用のコードチャンネルが自動生成**される
- チャンネル内は **会話 / 計画 / コード差分 / HTMLライブプレビュー** のタブ構成
- チームメンバー全員が作業を追跡し、途中でフィードバックを与え、**マージ前に承認**できる
- タスク完了時に**チャンネルは自動アーカイブ**、記録用の**監査ログ**を保持
- 提供開始時点で**全プランで利用可能**

狙いは「ターミナル内の個人作業だったAIコーディングをグループチャットへ引き出す」こと。

### トピック2: Bun 1.4 リリース — 本体を Zig から Rust へ全面書き換え
📅 2026年8月20日公開（出典: Bun Blog / AlternativeTo / daily.dev）

JavaScriptランタイム Bun がバージョン1.4を公開。**約535,496行のZigコードをRustへ全面移植**した初のリリース。

- 移植作業は Jarred Sumner 氏が **Claude Code のワークフローを約50本、11日間**走らせて実施
- **Bun.WebView** を内蔵 — Puppeteer / Playwright 不要でヘッドレスブラウザ自動操作。macOSはシステムWebKitを利用（追加インストール不要）、Chrome / Chromium / Edge の駆動にも対応
- **Bun.Image、Bun.markdown、JSON5、JSONL、Terminal、cron API** を標準搭載
- **Node.js 26.3.0 互換で1,517件のテストが新規合格**（1.0以降で最大の伸び）
- オプトインの**グローバル仮想ストアでインストール最大7倍高速化**
- アイドル時CPU使用率1/5、HTTPサーバのメモリ48%削減、Linux起動50%高速化、バイナリ約20%小型化

一方、**AI支援による大規模書き換えの信頼性**についてはコミュニティで慎重論も出ている。

### 💻 トピック3: Go 1.27 正式リリース — 4年越しのジェネリックメソッド解禁
📅 2026年8月19日公開（出典: go.dev / Phoronix / Linuxiac）

Go 1.26 から半年、**Go 1.27 が正式リリース**。最大の言語機能追加は **ジェネリックメソッド**。

- メソッド宣言が**レシーバ型の型パラメータに加えて独自の型パラメータを宣言可能**に
- 従来はパッケージ全体をスコープとする関数でしか書けなかった処理を、**特定の型の名前空間内**に置ける
- **制約: 具象型のメソッドのみ対象**。インターフェースメソッドは引き続き型パラメータ不可、**リフレクション経由での型引数指定呼び出しも未対応**
- その他: **encoding/json/v2**、標準 **uuid** パッケージ、**goroutineリークプロファイル**、サイズ特化アロケーションで**小オブジェクト割り当てコスト最大30%削減**

### 💻 トピック4: Rust 1.98.0 安定版 — 浮動小数点の代数的メソッドを安定化
📅 2026年8月20日公開（出典: Rust Blog / Phoronix / Linuxiac）

**Rust 1.98.0** が stable に到達。

- **f32 / f64 に代数的（algebraic）メソッド**を追加。加減乗除と剰余について、**実数の代数的性質を用いた最適化をコンパイラに許可**する。C の `-ffast-math` に近い発想で、演算順序の入れ替えや融合が可能になり数値計算ループが高速化しうる（**厳密なIEEE準拠結果は保証されなくなる**点に注意）
- 整数のシリアライズを **`format_into` メソッドと `NumBuffer`** で標準化。ベンチマークでは長年のデファクトである **itoa クレートと同等の性能**
- **文字列スライス、UTF-16変換、アトミック操作**まわりの新APIを追加、`ManuallyDrop` の挙動に関するドキュメントを安定化

rustup 利用者は `rustup update stable` で取得可能。

## まとめ

本日は、**AIコーディングの「場所」が変わる話**と、**ランタイム・言語の大型リリース3連発**でした。

Slack Code はエージェント作業をターミナルからチームチャンネルへ移し、レビューと承認をワークフローに組み込みます。Bun 1.4 は本体のRust書き換えとブラウザ自動操作の内蔵という二段構えで、その移植自体がAIエージェントによって行われた点も象徴的です。言語コーナーでは、Go がついにジェネリックメソッドを解禁し（ただし具象型限定）、Rust は浮動小数点最適化の新しい選択肢を提供しました。

**Go 1.27（8/19）、Bun 1.4・Rust 1.98.0・Slack Code（8/20）** と、この2日間にリリースが集中した週末でした。
