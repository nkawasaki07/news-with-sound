### トピック1: グーグル、完全準同型暗号でAIモデルを動かすコンパイラ「HEIR」発表

📅 2026年8月19日公開（出典: Publickey）

グーグルが、学習済みAIモデルを**暗号化されたデータのまま推論できる形に変換する**オープンソースコンパイラ「HEIR」を発表しました。基盤技術は**完全準同型暗号（FHE）** — データを復号せずに計算できる暗号方式です。

使い方はシンプルで、**Pythonコード上でどのデータをシークレットのまま扱うかをアノテーションで指定**すれば、コンパイル時にHEIRが自動でFHE対応ロジックへ変換します。

応用事例として、暗号化されたネットワークトラフィックをそのまま解析する侵入検知（既存IDS「Kitsune」をHEIRでコンパイル）、クレジットカード不正検出、ディープラーニングによるレコメンド、ホットワード検出の4件が示されました。グーグルはHEIRを**FHEの業界標準コンパイラ**に育てる方針です。

### トピック2: Next.js、8月26日にセキュリティリリース — クリティカル1件を修正

📅 2026年8月20日公開（出典: Next.js公式ブログ）

Next.jsが**8月26日のセキュリティリリースを事前予告**しました。対象は**重大度クリティカルの脆弱性1件**で、**16.3.3 と 15.5.24** を公開予定。影響範囲・対象バージョン・アップグレード手順を含むアドバイザリも同時公開されます。

注目すべきは予告の仕組みそのもの。7月に開始した新しいセキュリティリリースプログラムにより、**従来の場当たり的パッチ配布から月次の予告制へ移行**しました。おおよその公開日と想定される最高深刻度を先に告知することで、チームが計画的にアップグレードを準備できます。

なお、**実際に悪用が確認されている緊急案件はスケジュール外で即時配信**されます。

### 🛠 トピック3: Docker社、新ハイパーバイザ「Docker VMM」パブリックベータ公開

📅 2026年8月20日公開（出典: Publickey ／ Docker社発表は8月12日）

Docker社が自社開発の新仮想化ハイパーバイザ **Docker VMM** をパブリックベータ公開しました。**Docker Desktop v4.86** から Windows / macOS 両対応です。

主な改善点は4つ。

- **高速起動** — コンテナ起動が全体的に高速化
- **ファイルI/Oの改善** — ホストとコンテナ間のファイル共有が劇的に高速化、ビルドごとに体感できるレベル
- **メモリ管理の改善** — コンテナがアイドル状態になると使用メモリをホストOSに返却
- **Windowsでの安定性向上** — Docker初の自社開発ハイパーバイザ提供

Docker社は Windows において「**WSL並みの性能とHyper-V並みの分離を同時に実現**」と説明。正式版は**2026年10月末が目標**で、その時点でWindows/Mac/Linux版すべてのデフォルトエンジンになる予定です。

### 🛠 トピック4: 「Cloud Native Buildpacks」がCNCF卒業プロジェクトに

📅 2026年8月19日公開（出典: Publickey ／ CNCF発表は8月11日）

CNCFが **Cloud Native Buildpacks の Graduated（卒業）**を発表しました。卒業とは「本番環境でも安心して使えるほど十分に成熟した」という認定ステータスです。

Cloud Native Buildpacks は、**アプリのソースコードから言語（Java・Python・Go・Node.js・Ruby等）を自動検出し、依存関係のインストールとイメージのレイヤリングまで自動化**して、業界標準のOCIコンテナイメージを構築するツール。つまり **Dockerfileを書かずにコンテナが作れる**のが最大の特徴です。

起源はHerokuのBuildpackで、Cloud Foundryの採用を経てCNCF傘下へ。すでに**AWS・Google Cloud・Microsoft Azure**の主要クラウドでサポートが進んでいます。今後は**OCIアーティファクトのサポート拡大、SBOM対応ワークフローの強化、WebAssemblyを含む次世代ワークロード形式との互換性向上**に注力するとのことです。
