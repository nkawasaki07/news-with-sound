### トピック1: Googleが音声合成モデル「Gemini 3.8 Flash TTS」を公開
📅 2026年9月23日公開（出典: Unite.AI）

Googleが**Gemini 3.8 Flash TTS**と、大量処理向け低コスト版の**Gemini 3.8 Flash-Lite TTS**を、**Gemini APIとGoogle AI Studioで同時公開**しました。

- ベースは**Gemini 3 Pro**。入力はテキスト最大**8,000トークン**、出力は音声最大**64,000トークン**
- 対応言語は方言を含め**100以上**、利用できる声は**30種類から2,000種類以上**へ大幅拡大
- **セリフ単位で話し方を自然言語で指示**可能。30秒の音声サンプルからの声の再現、二人話者の台本形式、笑い声・ため息といった非言語表現にも対応
- 前世代のGemini 3.1 Flash TTSと比べ、**長尺コンテンツと二人話者の制御**が改善

### トピック2: Safari Technology Preview 253 が公開
📅 2026年9月23日公開（出典: WebKit Blog）

macOS Golden Gate／Tahoe向けに**Safari Technology Preview 253**が公開されました。

- **CSS**: コンテナクエリの条件内で **`sibling-index()` / `sibling-count()`** が利用可能に（兄弟要素の順番をCSSだけで条件分岐に使える）。あわせて `CSSContainerRule.conditions`、東アジア系カウンタースタイルの数値範囲拡張に対応
- **JavaScript**: `Intl.PluralRules` が **BigInt** を受け付けるように。大きなBigIntの乗算に**Toom-3アルゴリズム**を導入し高速化
- **Web API**: `QuotaExceededError` が **DOMExceptionのサブクラス**として独立（window／worker両スコープで利用可）。容量超過エラーの切り分けが容易に
- **SVG**: `<textPath>` に **`path` 属性を直接指定**でき、別の `<path>` を `href` 参照せずにテキストを曲線へ沿わせられる
- **Web Inspector**: ネットワークスロットリング（通信速度制限）を追加。**Web Extensions** では `offscreen` API に対応

### 🔒 トピック3: Next.js に緊急のリモートコード実行脆弱性、臨時パッチ公開
📅 2026年9月22日公開（出典: Next.js公式ブログ / Vercel）

Vercelが**Next.js 16.3.6（Active LTS）と 15.5.26（Maintenance LTS）**を**臨時（out-of-band）**でリリースしました。

- 対象は **`next/og` の `ImageResponse`（Node.js実装）**。SVG生成ライブラリ **Satori のエスケープ処理不備**が、上流依存の脆弱性と組み合わさり**リモートコード実行（RCE）**に至るおそれ
- 深刻度 **Critical**。影響範囲は **`>=16.2.0 <16.3.6`**、修正版は **16.3.6**
- **Edge版の `ImageResponse` は影響なし**。15系は本脆弱性の影響を受けないが、関連するハードニングを含む15.5.26を提供
- アドバイザリは **GHSA-vcvr-r3jv-pc5j**（Next.js）／**GHSA-wx4j-mvgx-mqwp**（Satori）
- 加えて **9月30日に定例セキュリティリリース**（16.3.7／15.5.27）を予告。Critical 1件・High 2件を含む**計9件**を修正見込み

### 🔒 トピック4: WordPressの重大脆弱性 CVE-2026-87902、公開当日から悪用
📅 2026年9月22日公開（出典: Patchstack / The Hacker News / セキュリティ対策Lab）

WordPress本体の**パストラバーサル／ローカルPHPファイルインクルード**脆弱性が公開され、**同日中に攻撃が開始**されました。

- 影響範囲は **4.7.0〜7.1.1** と極めて広い。修正版は **7.1.2**、旧ブランチにも 7.0.6／6.9.9／6.8.10 など **4.7.37まで**提供
- Patchstackは公開当日 **11:49 UTC に初の悪用試行**、**15:34 UTC にファイル書き込み試行**を観測
- **翌日には攻撃トラフィックが初日の10倍超**に増加、公開スキャンツールの流通も確認
- セルフホスト運用のWordPressは**優先度を上げた更新確認**を推奨
