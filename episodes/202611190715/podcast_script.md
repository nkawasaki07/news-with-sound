### トピック1: マイクロソフト、コーディング用AIモデル「MAI Code 2」「MAI Code 2 Flash」を発表
📅 2026年11月18日公開（出典: Publickey、The Decoder）

Microsoft Ignite 2026で、自社開発のコーディングモデル **MAI Code 2**（フラグシップ）と **MAI Code 2 Flash**（低価格版）が発表されました。

- **MAI Code 2**: 本番向けコード生成、難しいデバッグ、リポジトリ推論、ダッシュボードなどのUI構築が得意。**GitHub Copilotで利用可能**
- 社内ベンチマーク（4種の平均）で **GPT 6.1 Solの98%の性能を40%のコスト**、Claude Opus 5.5の96%の性能を5%のコストで実現と主張（**Microsoft発表値、第三者検証なし**）
- Copilotでの価格（100万トークンあたり）: **入力$0.50／出力$2.50**（プロモーション価格、2027年5月17日まで）→ その後 入力$1／出力$5
- **MAI Code 2 Flash**: コード解説・局所的な編集・ルーチン修正向け。入力$0.05／出力$0.25（その後$0.10／$0.50）。**Foundryで限定プレビュー**
- 日常的な企業向けコーディングが想定で、**長時間のエージェント作業にはまだ最適化されていない**とされる

### トピック2: Vercel Labs、AIエージェントがUIを組み立てる「UI SDK」をベータ公開
📅 2026年11月13日公開（出典: MarkTechPost、AlphaSignal）

Vercel Labsが、**コーディングエージェントが検証済みのUI動作を組み合わせてアクセシブルなコンポーネントを作る**ためのOSSライブラリ「UI SDK」を**パブリックベータ**で公開しました。

- 完成済みコンポーネントではなく、**50以上の「振る舞い（behavior）」を提供するヘッドレスライブラリ**
- 例: `createRovingFocus`（矢印キー移動）、`createTypeahead`（文字入力ジャンプ）、`createPopup`、`createSelection`、`createReorder` を組み合わせてSelect・コンボボックス・タグ選択などを構築
- **フォーカス管理・キーボード操作・ARIA属性が標準で組み込み済み**、スタイルはアプリ側で決定
- 対応: **React、Vue、Svelte、Solid、Web Components**（共通コアから各アダプターを生成）。エージェントがUIを操作するブリッジも同梱
- ライセンスは **Apache 2.0**。ベータのため**APIは変更の可能性あり**

### 📱 トピック3: Flutter、ネイティブコードを直接呼び出す仕組みが安定版に
📅 2026年11月12日公開（出典: Flutter公式ブログ）

Flutterチームが、Dartからネイティブコードを直接呼び出すツールの**安定版**を発表しました。

- **FFIgen（Objective-C向け）** と **JNIgen（Java/Kotlin向け）** が安定版に。ネイティブAPIからDartのバインディングを自動生成（C向けFFIgenは以前から安定版）
- 従来の**プラットフォームチャネルはシリアライズと非同期の往復**が必要で、遅延や記述量が課題 → 直接呼び出しで**同期呼び出しやバックグラウンドIsolateからの呼び出しも可能**に
- **Pigeon v30以降**に、内部でFFIgen/JNIgenを使う「ネイティブ相互運用」モードを**プレビュー**提供。`SwiftOptions(useFfi: true)`、`KotlinOptions(useJni: true)` の設定と再生成で移行でき、`shared_preferences` が移行例
- 対応は **Android・iOS・macOS**。Windows/Linuxは従来のプラットフォームチャネルを継続
- FFIgen/JNIgen単体は低レベルで、**メモリ管理とスレッド処理は開発者の責任**

## まとめ

- **MAI Code 2**: Copilotで使える低価格コーディングモデル。性能・価格比は発表元の数値なので、自分のタスクで要検証
- **Vercel UI SDK**: エージェントが作るUIのアクセシビリティを「振る舞い」部品で底上げするアプローチ（ベータ）
- **Flutter**: FFIgen/JNIgenが安定版、Pigeonのネイティブ相互運用はプレビュー。プラグイン開発者は移行の検討を

AIがコードを書く時代に、モデルの価格、UIの部品、ネイティブとの橋渡しと、各レイヤーで開発体験の改善が進んでいます。
