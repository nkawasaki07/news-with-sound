### トピック1: Claude Codeが「オートモード」を既定に、承認疲れへの回答
📅 2026年8月10日公開（出典: BigGo Finance／Anthropic発表は8月7日）

Anthropicは**8月14日から、Claude CodeのPro・Max・Teamプランでオートモードを既定**に切り替える。取り消し不能・破壊的・利用者の環境外に向かう操作を除き、逐一の承認なしでコマンドを実行する。

根拠として示されたのは1053人の有料テスターによる社内調査で、**危険なコマンドの検出率はオートモードが89%、手動レビューは13.6%**。同社はこれを「承認疲れ」と説明し、利用者が**確認プロンプトの97%を反射的に許可**している実態を挙げた。

第三者のTrajectory Labsの検証では、72種のプロンプトインジェクション攻撃を**すべて遮断**（Codex上のGPT-5.6 Solは5.83%が成功）。プロンプトインジェクション検査と、管理者が特定操作を恒久的に禁止できる**ハード拒否ルール**も追加された。Enterpriseプランとapi経由の利用は9月以降。

### トピック2: Cloudflareが「WebMCP」を開発者プレビュー公開、トグル1つでサイトをエージェント対応に
📅 2026年8月11日公開（出典: byteiota／原典: Cloudflare Blog・InfoQ）

CloudflareがAgents Weekの一環として**WebMCP**を公開した。WebMCPはブラウザの新API `navigator.modelContext` を通じ、検索・カート追加・予約といった**呼び出し可能なツールをAIエージェントへ直接提示する**W3C Draft Community Group仕様。サーバー側MCPと違い、**ブラウザタブ内で動作しユーザーの既存セッションを引き継ぐ**点が特徴だ。

Cloudflareの実装は**HTMLRewriterでブリッジスクリプトを配信時に注入**するため、**オリジンの改修も再デプロイも不要**。未対応ブラウザでは何も登録せず静かに終了するので、人間の訪問者への影響はない。ダッシュボードの Agent Readiness > Labs から有効化する。

提供されるツールパックは2種。**Content Credentials**（画像のC2PA来歴メタデータを公開）と、**Site MCP Server**（既存のサーバー側MCPをブラウザ文脈へ橋渡し）。Chromeのネイティブ対応は146でフラグ付き、**オリジントライアルは149から**という段階にある。

同社の調査では上位20万ドメインのうちMarkdownコンテンツネゴシエーション対応は3.9%、AI利用方針の宣言は4%。**構造化ツール呼び出しはDOMスクレイピング比で約89%のトークン削減**になるという。

### 💻 トピック3: Rustの新借用チェッカー「Polonius Alpha」がnightlyで既定有効に
📅 2026年8月4日公開（出典: Rust Blog／解説記事は8月11日・byteiota）

Rustチームが**8年越しの研究成果Polonius Alpha**をnightlyで有効化した。**nightly-2026-08-06以降**で既定オン、既知のブロッカーはなしとしている。

従来のNLL（非字句的ライフタイム）はスコープ・リージョン単位で寿命を推論するため、実行経路上は安全なコードも拒否していた。Poloniusは**「この地点でどのローン（貸し出し）が生きているか」を追うフロー感度モデル**に切り替え、有名な**NLL Problem Case #3**（HashMapの `get_or_insert` パターン）や、GATを使った**lending iteratorのfilter**が通るようになる。

トレードオフは明確で、**コンパイル時間が10〜20%増**するケースがある。チームは「安定化に向けて許容できる」と判断した。メモリ安全性の保証は不変で、unsafeが緩むわけではない。切り替えは `-Zpolonius=next` / `-Zpolonius=off`。**年内の安定化**を目指す。

### 💻 トピック4: Go 1.27、ジェネリックメソッドとJSON新エンジンが今月GAへ
📅 2026年8月2日公開・8月11日追報（出典: Northeast Times／byteiota）

**今月中の正式リリース**が見込まれるGo 1.27。目玉は**ジェネリックメソッド**で、メソッド宣言がレシーバとは独立に自前の型パラメータを持てるようになる。4年越しの制限解除だ。

JSON周りも大きい。実験扱いだった **encoding/json/v2 と encoding/json/jsontext が `GOEXPERIMENT=jsonv2` なしで利用可能**になり、**従来のv1も内部実装がv2に置き換わる**。ただしv2は**不正なUTF-8や重複キーを拒否する厳格な既定値**を持つため、アップグレード時は挙動差の確認が要る。

そのほか、FIPS 204のポスト量子署名を実装した **crypto/mldsa**（MLDSA44/65/87）、**標準ライブラリへのuuidパッケージ追加**、**80バイト未満の小規模アロケーションが最大30%低コスト**化、ゴルーチンリークのランタイム報告などが入る。なお8月25日にはGoチーム登壇のリリースパーティも予定されている。

## まとめ

本日は「エージェントにどこまで委ねるか」という主題が2件並んだ。Anthropicは**人の承認より分類器のほうが危険を止められる**という数字を示してオートモードを既定化し、Cloudflareは**サイト側からエージェントに構造化された手がかりを差し出す**経路を用意した。どちらも、スクレイピングと逐一承認という現状のコストに対する回答である。

一方、言語コーナーのRustとGoは対照的に地味で本質的だ。**Poloniusは「本来通るべきコードが通らない」問題の解消**、**Go 1.27はジェネリクスとJSONという日常の道具の作り直し**。コンパイル時間+10〜20%やJSONの厳格化といった実コストも伴うので、導入は自分のコードベースで測ってから判断したい。
