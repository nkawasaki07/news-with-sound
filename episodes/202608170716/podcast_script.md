VSCode向けGit拡張の新バージョン **GitLens 19** が公開されました。目玉は、リポジトリ履歴の可視化ツールだった**コミットグラフをゼロから作り直し、開発の中心となるワークベンチへ再定義**した点です。

### トピック2: VercelのBunランタイムが `Bun.serve` をエントリポイントとして直接受け付けるように
📅 2026年8月10日公開（出典: Vercel Changelog）

Vercel Functions の Bun ランタイムで、**`Bun.serve()` を関数のエントリポイントに指定できる**ようになりました。`Bun.serve` は高速JS実行環境 Bun 組み込みのサーバー起動機構です。

- **フレームワークでラップする必要がなくなり**、ローカルで動かすサーバーをそのままデプロイ可能
- 有効化は `vercel.json` に `"bunVersion": "1.x"` を書くだけ
- **WebSocketハンドラに対応**。接続は Fluid compute の**アクティブCPU課金**で動作し、**メッセージ処理中の時間のみ課金**、アイドル接続時間は無料
- 1接続はその生存期間中ひとつのインスタンスに固定される一方、**1インスタンスが複数の同時接続を処理**可能

### 🔒 トピック3: macOS画面共有の脆弱性 CVE-2026-65400 が実際に悪用、CISAが深刻度を9.8へ引き上げ
📅 2026年8月14日公開（出典: The Hacker News / BleepingComputer / Tom's Hardware）

Appleが**8月6日に緊急パッチ**で修正した **CVE-2026-65400** の**実環境での悪用**が確認されました。

- 該当箇所は画面共有機能を支えるシステムデーモン **`screensharingd`**。**有効な認証情報なしでリモートコード実行**が成立
- オランダ **NCSC の勧告 NCSC-2026-0280** によると、**ポート5900がインターネットに露出**した複数システムで **root権限が奪取**され、**確認された全事例で Monero マイナーが設置**
- **CISA はパッチ公開の8日後、CVSSを 7.1 → 9.8（Critical）へ再評価**
- 対処は **macOS Tahoe 26.6.1 / Sequoia 15.7.9 / Sonoma 14.8.9 への更新**、または**画面共有の無効化のみ**
- VNCパスワードのローテーションや承認ユーザーの削除といった一般的なハードニングは**無効**。デーモンが接続を「認証済み」として扱う地点より下流の制御であるため

### 🔒 トピック4: 実行中のChrome / EdgeにDevTools Protocolを後付け有効化する手法が公開
📅 2026年8月14日公開（出典: The Hacker News）

Windows上で**すでに起動しているChrome / Edgeプロセスに対し、Chrome DevTools Protocol（CDP）を後から有効化する**ポストエクスプロイト手法が公開されました。CDPは開発者ツールがブラウザを制御するための内部プロトコルです。

- 有効化されると **Cookie・保存データ・認証済みセッションへ直接アクセス**可能
- **これはChrome / Edgeの脆弱性を突くものではない**。前提として**攻撃者が既に当該Windowsホストでコード実行できている**必要がある
- したがって**ブラウザへのパッチでは防げない**類の手法であり、防御の要は**端末上での任意コード実行を許さないこと**にある
