### トピック1: OpenAIのDecisions APIが一般提供に、プロンプトキャッシュは12時間保持へ
📅 2026年10月22日公開（出典: OpenAI API Changelog）

あらかじめ決めた選択肢から答えを選ばせる **Decisions API（gpt-6-luna）が一般提供** になりました。「文が正しい確率（Predicates）」「選択肢の選択（Choices）」「数値スコア（Scores）」を返す、判定に特化したAPIです。

- **共通入力のキャッシュに対応**（プロンプトキャッシュ割引が適用）
- 個々の質問の指示に**画像を含められる**、構造化データを `input_json` で直接渡せる
- 1リクエストあたりの質問数が **200→400** に拡大

あわせて10/20には、Responses APIで **12時間保持のプロンプトキャッシュ** が追加されました。ただし **キャッシュ書き込みは入力料金の2.5倍** なので、呼び出し間隔と再利用回数を見て使い分けが必要です。問い合わせのルーティングやエージェントの次アクション選択に向いています。

### トピック2: Cloudflare、TypeScriptをRustに移植した「tsrs」を発表
📅 2026年10月22日公開（出典: Publickey）

Cloudflareが **TypeScriptコンパイラのRust移植「tsrs」** を発表しました。**フォークではなくTypeScriptチームと協力**して開発しているとしています。

- 型チェックが **Go製TypeScript 7比で最大8倍速く、メモリ約70%減**（※開発元のベンチマーク）
- **WASMで動作**し、ブラウザやCloudflare Workers上でも利用可能、`npx tsrs` で実行
- **現時点では全機能未対応**、LSPを含む全機能のサポートは今後の予定
- 近く **Oxcツールチェーンの一部** になる予定、ソースはGitHub（oxc-project/tsrs）

### 🔒 トピック3: PHPに認証不要のRCE脆弱性2件、修正版が公開
📅 2026年10月22日更新（出典: gihyo.jp）

PHPセキュリティチームが10/21に、**CVSS v4.0で9.2の脆弱性2件** を修正したリリースを公開しました。

- **CVE-2026-109618**: メモリ不足時にリクエスト用内部データの初期化が中断され、不完全な状態が終了処理で使われる
- **CVE-2026-109619**: 終了したリクエストの内部状態が残り、解放済みメモリへの参照が次のリクエストで使われる

いずれも **認証なしでリモートコード実行** の恐れがあり、**PHP-FPMとmod_phpで成立を検証、mod_phpが最もリスクが高い** とされます。

- 修正版: **PHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35**（7.4〜8.1はソースで最小限の修正のみ）
- 緩和策（`memory_limit=-1`、`session.upload_progress.enabled=0` など）は **一時的な対策** にすぎない
- WordPressは本体更新不要、**サーバー側のPHP更新** が必要。WAFも修正の代わりにはならない

### 🔒 トピック4: Linuxカーネルにゲスト→ホスト脱出の脆弱性「PwnEscape」
📅 2026年10月16日公開（出典: Cybernews、Publickey）

**CVE-2026-99999（通称PwnEscape、深刻度9.3）** は、ゲストVMからホスト側Linuxで不正なコードを実行できる可能性がある脆弱性です。

- 原因は **KVM本体ではなくIPv4スタック**、ゲストパケットのチェックサムを計算する `skb_checksum_help` 周辺
- 研究者がラボで **ホストメモリの読み出しと64バイトの書き込み** を再現。ホスト掌握までの手順は続報予定
- **実環境での悪用は未確認**
- 修正は10/8に受理、**10/14にメインラインへマージ**。**未配布のディストリビューションもある** ため、仮想化基盤の運用者は配布状況を確認
