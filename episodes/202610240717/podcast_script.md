### トピック1: Agent SkillsやOpen ResponsesがAgentic AI Foundationへ
📅 2026年10月23日公開（出典: gihyo.jp。AAIFとAnthropicは10月22日に発表）

Linux Foundation傘下の**Agentic AI Foundation（AAIF）**が、4つのプロジェクトの受け入れを発表しました。これで傘下のプロジェクトは**計10件**になります。

- **Agent Skills（Anthropic）**: `SKILL.md`とスクリプト・資料を1つのフォルダーにまとめ、複数のエージェントで再利用する形式。必要な情報だけを段階的に読み込みます。今後は複数の組織から成る技術運営委員会（TSC）が開発方針を示します。
- **Open Responses（OpenAI）**: Responses APIを土台に、**各社のモデルを共通の形式で呼び出す**ための仕様。リクエストとレスポンスの構造、ストリーミング、ツール呼び出しの形式を共通化します。
- **OpenEnv（Hugging Face）**: エージェントの強化学習用の環境を、共通APIで扱うフレームワーク。環境はDockerイメージで配布します。
- **OpenSandbox（Alibaba）**: **Docker/Kubernetes上にエージェント用の隔離環境**を作るための基盤です。

### トピック2: Node.jsが10月のセキュリティリリースを公開
📅 2026年10月21日公開（出典: Konfirmity、LinuxCompatible）

修正版は **v22.23.4／v24.22.1／v26.12.1** です。修正された脆弱性は**10件**で、内訳はHigh 4件、Medium 3件、Low 3件です。

- **CVE-2026-111497（High）**: 同梱のBrotliデコーダーの**範囲外書き込み**。Node.jsはリモートコード実行につながり得るとしています。信頼できない圧縮データを展開するアプリが影響を受けます。
- **CVE-2026-106069 / CVE-2026-105483（High）**: `0127.0.0.1`のような非正規のIPアドレス表記や全角数字を使って、**TLSのホスト名検証を回避**できる問題。
- **CVE-2026-105482（High）**: DNS解決で、名前がNUL文字のところで切り詰められる問題。
- **CVE-2026-106074**: スナップショットやSEA（単一実行ファイル）で乱数が繰り返される問題。修正版でのアプリの**再ビルドが必要**です。

**EOLのNode.js 20には修正版がありません**。なお、CVSSスコアは公表されていません。

### 🛠 トピック3: GitHubがパッケージファイアウォールをプレビュー公開
📅 2026年10月20日公開（出典: GitHub Changelog）

**GitHub package firewall**は、エンドポイントやCI/CDホスト、コーディングエージェントと、上流のパッケージレジストリの間に入るポリシーゲートです。**インストールの時点で悪意のあるパッケージを止めます**。

- 判定の対象は、メタデータのリクエストとパッケージのダウンロードの両方です。
- 管理者は、**クールダウン期間**、**GitHub Advisory Database**に基づくマルウェア・脆弱性の確認、**attestationのダウングレード検知**などをポリシーとして設定できます。
- 正当なパッケージがブロックされた場合は、エラーメッセージのURLから例外を申請できます。
- 対象は**GitHub Enterprise Cloud**です。プレビュー期間中は無料で、GA後はActionsと同様の従量課金になる予定です。**今のところ対応はnpmのみ**です。

## まとめ

AIエージェントの分野では、スキル、API呼び出し、実行環境の**共通規格がベンダー中立の団体に集まりつつあります**。足元のセキュリティでは、Node.jsの更新と、npmのサプライチェーン対策が今週の大事なポイントです。Node.jsを使っている方は、**まず運用中のバージョンを確認**してください。
