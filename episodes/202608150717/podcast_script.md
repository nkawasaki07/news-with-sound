### トピック2: 主要3社の推論APIに欠陥、暗号化された「隠れた思考」が第三者に読めた

📅 2026年8月12日公開（出典: The Hacker News / Tech Times）

OpenAI・Anthropic・Googleの推論APIに共通する設計欠陥が公表されました。**3社とも推論トークンの暗号化に単一のグローバル鍵を使っていた**ことが原因です。

- あるセッションで生成された暗号化リーズニングブロックを、**別セッションへリプレイ（再生）できてしまう**
- さらに**同じ提供元の「弱いモデル」に渡すと、隠された中身を喋らせられる**（デコーダーリングとして悪用）
- ELLIS Institute と Max Planck Institute の研究チームが**315,320件**の隠れた推論ブロックを復号、公開ログから**実在する認証情報182件**（APIキー・パスワードを含む）を抽出
- 論文「Stealing Reasoning Traces from Proprietary LLM APIs」が示した悪用経路は4つ — **推論の窃取による蒸留 / 他ユーザーの非公開データ抽出 / 安全な回答の裏に有害コンテンツを隠蔽 / 不透明ブロック内へのプロンプトインジェクション**

各社の対応は分かれており、**Anthropicは「thinkingブロックは生成したモデルに紐づくため、モデル切り替え時には除去すべき」**という方針を明示しています。

### トピック3: AIエージェントの拡張機能に共通規格「Agent Plugins 1.0.0」が登場

📅 2026年8月10日公開（出典: Publickey / AWS Blog / Google Developers Blog）

**Agent Skills と MCPサーバー設定を1つのポータブルな「プラグイン」に束ねる**ベンダー中立仕様が発表されました。

- ディレクトリ構成は `plugin.json` ＋ `skills/`（SKILL.md）＋ `mcp.json` というシンプルな形
- 技術運営委員会（TSC）の**創設メンバーは AWS・Cursor・Microsoft・OpenAI・Vercel**
- **GitHub Copilot、VS Code、Cursor、ChatGPT、Codex、AWS Kiro** が対応表明
- 設計思想として、**あえて「小さな相互運用の土台」だけを定義**。配布方法・インストール・権限管理・UI・クライアント固有機能は各実装の裁量に委ねている

なお、SkillsとMCPを最初に打ち出した**Anthropicはこの枠組みに参加していません**。

### 🛠 トピック4: CodeRabbitが「Agentic Change Management」を発表、プルリクエストが最後の詰まりどころに

📅 2026年8月12日公開（出典: The New Stack / InfoWorld / SD Times）

AIコードレビューのCodeRabbitが、**人間とAIエージェント双方が生む変更を統制するコントロールレイヤー**を発表しました。

- 同社の主張は**「Issue tracking is dead（課題管理はもう死んだ）」**。Jira・GitHub Issues・Linearなどは、PMが時間をかけてバックログを整理し開発者に割り振る、という前提で作られていた
- 現在は変更指示が**開発者・非エンジニア・コーディングエージェント・課題トラッカー・サポートシステム・自動テレメトリパイプライン**など多方向から流入する
- その結果、すべてが合流する**プルリクエストがSDLC最後のチョークポイント**になっているという分析
- 新機能は**リポジトリ全体の文脈・組織の規約・チームの知識・隔離テスト環境での実行結果**を突き合わせ、**マージ前チェック**として検証を行う

「AIがコードを書く速度に検証が追いつかない」という課題への、一つの構造的な回答です。
