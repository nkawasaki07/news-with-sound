### トピック2: Chrome 154 安定版が公開 — CSSとWeb Cryptoに新機能
📅 2026年9月22日公開（出典: Chrome for Developers）

Chrome 安定版154が9月22日に公開されました。Chromeは今月から**2週間リリースサイクル**へ移行しており、153に続く2本目のリリースです。

**CSS / UI**

- `scroll-marker-group` に **`links` / `tabs` の2モード**を追加。カルーセルのインジケーターを「ナビゲーションのリンク列」として扱うか「タブリスト」として扱うかを選べ、**フォーカス順序とARIAロールが切り替わる**
- `text-decoration-inset`: 下線・上線・打ち消し線の**開始/終了位置をずらせる**（背景グラデーションによる擬似実装が不要に）
- `text-decoration-skip-spaces`: 装飾線が**空白文字をスキップ**するかを制御
- ポップオーバー／ダイアログの**ライトディスミスを`click`イベント基準に変更**。タッチのスクロール操作や右クリックで閉じなくなった

**JavaScript / Web API**

- `Iterator.prototype.includes()` を追加
- `WebSocket` コンストラクタに**オプションバッグ**（`{ protocols }`、`targetAddressSpace`）を導入
- Web Cryptoに**耐量子アルゴリズム**を追加: **ML-KEM、ML-DSA、X-Wing、ChaCha20-Poly1305**
- `insertAdjacentHTML()` を置き換える位置指定系メソッドと、`streamAppendHTML()` などの**ストリーミング挿入API**

### 💻 トピック3: Node.js 26.10.0 リリース
📅 2026年9月22日公開（出典: Node.js リリースノート）

JavaScriptランタイム **Node.js 26.10.0** が公開されました。注目は標準機能の3つの追加です。

- **`crypto.parsePKCS12()`**: 証明書と秘密鍵をまとめたPKCS#12形式を**標準APIで解析可能に**
- **`openAsBlobSync()`**: ファイルをBlobとして開く処理の**同期版**
- **`util.throttle()`**: 短時間に連続呼び出しされる関数の実行頻度を間引く**スロットリングが標準ライブラリだけで完結**

いずれも**これまで小さな外部パッケージに依存しがちだった処理**で、サプライチェーンリスクの観点でも依存を減らせる追加です。

### 💻 トピック4: GPU並列実行言語「Bend 2」公開
📅 2026年9月21日前後公開（出典: Qiita プログラミング雑記 経由）

**GPUでの並列実行を前提としたプログラミング言語「Bend 2」**が公開されました。

最大の特徴は、開発者が定めた条件をプログラムが満たすかを、テストではなく**数学的な証明として検証できる（形式検証）**点です。**AIが生成したコードの誤りを実行前に排除する**ことを設計目標に掲げています。

AIによるコード生成量が人間のレビュー能力を上回りつつある状況で、**正しさの保証を言語機構そのものに組み込む**というアプローチは、同日のニュースで話題になった「認知負債」の議論とも響き合う方向性です。
