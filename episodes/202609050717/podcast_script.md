### トピック1: OpenAI、次世代旗艦モデル「GPT-6 Astra」を提供開始
📅 2026年9月3日公開（出典: OpenAI / CNBC / 窓の杜）

OpenAIが新しい旗艦モデル **GPT-6 Astra** を発表しました。APIのモデル名は `gpt-6-astra`、**コンテキスト長は1,050,000トークン**、最大出力128,000トークン、ナレッジカットオフは2026年4月30日です。

料金は100万トークンあたり**入力$10・出力$50**、キャッシュ済み入力は$1.00。272Kトークンを超えるプロンプトは入力・キャッシュが2倍、出力が1.5倍に課金される点に注意が必要です。

推論強度を指定する `reasoning.effort` に **`xhigh` と `max` の2段階が新設**され、low / medium / high / xhigh / max の5段階になりました。Web検索・ファイル検索・Computer use・MCP・Skills・ホステッドシェルなど主要ツールにも対応しています。

同社はコンピュータ操作・ブラウジング・ソフトウェアエンジニアリング・科学・サイバーセキュリティで最高水準と主張する一方、**自社のPreparedness Frameworkでサイバーセキュリティの「critical」水準に到達した初のモデル**と位置づけており、まずはサイバーセキュリティプログラム参加組織から段階的に提供されます。

### トピック2: Interop 2027の提案募集がスタート、締切は9月23日
📅 2026年9月3日公開（出典: Microsoft Edge Blog）

ブラウザ間の相互運用性を高める年次プロジェクト **Interop** の2027年版に向けた提案募集が始まりました。Interopは Apple・Google・Microsoft・Mozilla らが共同で「年内に全ブラウザで同じように動かす機能リスト」を選定し、達成度を公開スコアとして競う取り組みです。

募集対象として挙げられているのは次の3点です。

- **ブラウザごとに挙動が異なる**Webプラットフォーム機能
- 仕様はあるが**実務で頼りきれない**標準ベースの機能
- 相互運用性が改善されれば**新しい可能性が開ける**領域

**提案の受付は2026年9月23日まで**。Interopチームが選定プロセスで評価し、**最終的な Interop 2027 のスコープは2027年2月上旬に公開**される予定です。運営側は「強い提案に共通するのは、実在する開発者の問題を解決していること」と述べています。

### 🔒 トピック3: curl 8.22.0公開、9件のセキュリティ修正と10件のCVE
📅 2026年9月2日公開（出典: daniel.haxx.se）

事実上あらゆるシステムに組み込まれている通信ライブラリ **curl / libcurl がバージョン8.22.0** をリリースしました。通算276回目のリリースで、302件のバグ修正・525コミット・**9件のセキュリティ修正**を含みます。同時に**10件のCVE**（curl/libcurlで9件、wcurlで1件）が公開されました。

主なCVEは以下の通りで、**認証と接続再利用まわりに集中**しています。

- **CVE-2026-13608**: OpenLDAP SASL認証のバイパス
- **CVE-2026-18924**: HTTP/2 server pushにおけるuse-after-free
- **CVE-2026-80230**: OpenSSLの証明書ピンニングのバイパス
- **CVE-2026-80255**: タブ文字によるsecure cookie属性のバイパス
- **CVE-2026-19931 / 80231**: Negotiate・ネイティブCAストア利用時の不適切なコネクション再利用

機能面では **RFC 9421 HTTP Message Signatures の実験的サポート**とApple GSS Frameworkのサポートが追加され、一方で **TLS-SRPのサポートは廃止**、SPNEGO交渉におけるNTLMフォールバックもブロックされました。今後 HTTP/2 Server Push・NTLM・SMB の削除も予告されています。次回リリースは10月末の予定です。

### 🔒 トピック4: Chromeの「V8」にゼロデイ脆弱性、悪用を確認済み
📅 2026年9月4日公開（出典: 窓の杜）

Googleが**9月3日（現地時間）にデスクトップ版Chromeの安定チャネルを更新**し、12件の脆弱性を修正しました。深刻度はHighが10件、Mediumが2件で、Criticalは含まれません。

ただし、**JavaScriptエンジンV8の型の取り違え（Type confusion）の脆弱性「CVE-2026-85046」は、すでに実際の攻撃での悪用が確認**されており、早急な適用が推奨されます。

他にも V8の競合状態（CVE-2026-85045）、Compositingのuse-after-free（CVE-2026-85048）、**WebGLの境界外書き込み**（CVE-2026-85050）、DevToolsやSkiaのuse-after-freeなどが並びます。

Googleは**9月1日にも26件（うちCritical 2件）を修正**しており、今週これで2回目のセキュリティアップデートです。配布中のバージョンは Windows/Mac が **v152.0.7977.82/.83**、Linuxが **v152.0.7977.82**。自動更新されますが、**適用完了にはブラウザの再起動が必要**です。

## まとめ

生成AIでは **GPT-6 Astra** が登場し、推論強度に `xhigh` / `max` が加わるなど「長く考えさせる」方向の設計が一段進みました。Web標準側では **Interop 2027 の提案募集**が9月23日まで受付中で、ブラウザ差分に困っている開発者が声を上げる好機です。

セキュリティは足元の基盤ソフトが並びました。**curl 8.22.0** は認証・接続再利用まわりに9件の修正、**Chrome** はV8のゼロデイが悪用確認済み。どちらも「使っていない開発者はほぼいない」レイヤーですので、依存バージョンの確認とブラウザ再起動は本日中に済ませておきたいところです。
