### トピック2: Web標準動向2026年8月版 ─ CSSにワイルドカードクラスセレクタ採用が合意
📅 2026年9月1日公開（出典: サイボウズ フロントエンド / Zenn）

サイボウズのフロントエンドチームがW3C・TC39・WHATWGの8月分の動向をまとめました。実務に効く動きは以下の通りです。

- **CSS: ワイルドカードクラスセレクタ `.foo-*` の採用が合意**。ユーティリティクラスなど共通prefixを持つクラスをまとめて選択できます。一致の区切りを**ハイフンに限定**したのは、`.foobar` のような別単語への誤マッチ防止とパフォーマンスのため。
- **CSS Mixins が `@mixin` と `@private` に収束**。従来の `@result` は廃止され、逆に**内部変数側を `@private` で包む**構文へ。内部変数を使わないmixinは宣言をそのまま並べるだけで済みます。`@mixin` と `@macro` の2本立ても `@mixin` に統合。
- **JavaScript: `Iterator.prototype.join` がStage 4昇格提案**（9月のTC39第116回会合）。配列変換なしで `map.keys().join(', ')` と書けます。**Firefox 154で既定有効**、Chrome 153 betaでも利用可能。
- **`Composite` がStage 2昇格提案**。中身が同じなら同一参照になるオブジェクトを作れ、Map/Setのキーに値ベースの等価性を持ち込めます。
- **Firefox もXSLTの段階的廃止（Intent to Unship）を表明**。2027年8月に全チャネルで削除予定。

### 🔒 トピック3: 「GitSpawn」─ 悪意あるリポジトリを開くだけでAIエージェントが任意コード実行
📅 2026年9月3日公開（出典: Manifold Security、The Hacker News）

セキュリティ企業Manifoldが、**GitSpawn** と名付けた新しい脆弱性クラスを公表しました。**罠を仕込んだリポジトリをAIコーディングエージェントで開いた瞬間**に、プロンプト入力も承認クリックもなしにコードが実行されます。

原因はGitの設定項目 **`core.fsmonitor`**。ファイルシステム監視ヘルパを指定して高速化する機能ですが、**Gitはその値をリポジトリ内の `.git/config` から直接読む**ため、攻撃者が任意コマンドを仕込んでおけばインデックス更新時に起動されてしまいます。

影響が確認されたのは **Claude Code、goose、Hermes Agent、Qwen Code、Grok Build**、および亜種経由で **Codex と Cursor**。追跡された8件のうち goose（CVE-2026-72718）・Claude Code・Cursor には修正が出た一方、**9月1日の再検証時点で4件が未修正**。Hermesはベンダー無応答のため CVE-2026-71963 が独自採番されました。当面の防御は「**素性のわからないリポジトリをエージェントにいきなり開かせない**」ことです。

### 🔒 トピック4: CISAが実悪用の脆弱性7件をKEV追加 ─ Starlette・LiteLLMが対象
📅 2026年9月2日公開（出典: CISA、The Hacker News）

米CISAが**実際に悪用が確認された7件**をKEV（既知の悪用済み脆弱性）カタログに追加しました。開発者に直結するものが2件あります。

- **Starlette `CVE-2026-48710`（通称 BadHost）**: HTTPのHostヘッダに**不正な文字を1つ混ぜるだけ**で、ミドルウェアが評価する `request.url.path` を偽装可能。パスベースで認可をかけていると、ミドルウェアは偽のパスを見るのに実際のルートは実行されるため**認証を回避**されます。影響は **0.8.3〜1.0.0**、**修正版は1.0.1**。
- **LiteLLM `CVE-2026-59822`**: MCP Streamable HTTPエンドポイントに偽装した `Authorization` ヘッダを送ると **OAuth2パススルーのフォールバック経路**に入り、鍵の検証失敗が空の `UserAPIKeyAuth()` に置き換わる。結果、**有効なキーなしでMCPツールに到達**できます。**修正版は1.84.0**。

このほか SonicWall SMA1000（SSRF・OSコマンドインジェクション）、JFrog Artifactory、Kestra OSS、**Sangoma Switchvox（CVE-2026-9586、CVSS 9.3の未認証SQLインジェクション）** が対象。連邦機関向けの多くの対応期限は**9月5日**に設定されています。
