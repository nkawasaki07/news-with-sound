### トピック1: VS CodeとGitHub Copilotアプリに複数モデル連携の「HydraFusion」が登場
📅 2026年9月30日公開（出典: GitHub Changelog、Publickey）

GitHubは、複数のAIモデルを組み合わせて作業する **HydraFusion** を、**VS Code 1.140とGitHub Copilotアプリで研究プレビュー公開**しました。従来はCLI限定でした。

タスクに応じて3つの実行パターンを自動選択します。

- **Single**: 選ばれた1モデルが直接解く
- **Cascade**: 効率的なモデルが下書き → 品質ゲートで判定し、必要なら**強いモデルへエスカレーション**
- **Critique**: モデルAが作成 → **独立したモデルBがレビュー** → Aが1回修正

対象は **Copilot Pro / Pro+ / Business / Enterprise**。VS Codeではモデルピッカーから選択するか `chat.copilot.hydraFusion.enabled` を有効化。Business/Enterpriseは**管理者によるプレビュー機能の有効化が必要**です。

### トピック2: SvelteKit 3が正式リリース、設定はViteへ・`$lib`は`#lib`へ
📅 2026年10月1日公開（出典: Svelte公式、Netlify Changelog）

**SvelteKit 3.0** が正式リリースされました。主な破壊的変更は次のとおりです。

- **Vite 8が必須**（Rolldownによる高速ビルド）
- 設定が `svelte.config.js` から **Viteの設定ファイルへ移動**
- `$lib` エイリアスが Node.js標準のサブパスインポートを使う **`#lib` に置き換え**。`#lib/foo/index.ts` のように**ファイルを明示**する必要あり

新機能として、**`src/env.ts` で環境変数を宣言し検証・型安全化**、`goto()` の `shallow: true` 対応、エラーが一貫して `handleError` を通るよう改善、Service Worker用インポートの整理、**トレーシングの安定版化**などが入りました。

移行は `npx sv migrate sveltekit-3` でほぼ自動化。一方、型安全なクライアント・サーバー通信を担う**リモート関数は未完成**で、次フェーズの最優先課題とされています。

### 💻 トピック3: Python 3.15に異例のrc3、正式版は10月9日予定
📅 2026年10月2日公開（出典: Python公式、Real Python）

Python 3.15で**3回目のリリース候補（rc3）**が公開されました。原因は目玉機能の **遅延インポート（PEP 810）** に直前で見つかったリリースブロッカーです。

- `lazy import a.b as c` で **`b` をサブモジュールではなく属性として扱ってしまう**問題
- 遅延インポートしたサブモジュールに触れると、**兄弟サブモジュールまで読み込まれる**問題

rc2以降、82名のコントリビューターによる約156件の修正を含みます。**正式版は10月9日予定**。3.15には他にも `frozendict` / `sentinel` 組み込み型、**全プラットフォームでUTF-8既定**、標準ライブラリのサンプリングプロファイラ、JITの高速化などが入ります。遅延インポートを検証中の方は**rc3で再確認**しておきましょう。
