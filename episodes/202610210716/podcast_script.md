### トピック1: Claude Code Reviewが正式提供開始、レビューは約3倍高速に
📅 2026年10月15日公開（出典: Anthropic公式発表、Tech Bytes）

Anthropicは、プルリクエストを自動でレビューする**Claude Code Review**を、**Team・Enterpriseプランで正式提供（GA）**しました。

- 研究プレビュー時は約20分かかっていたレビューが、多くの場合**6〜10分**で完了し、**約3倍の高速化**
- 指摘は「**問題点・発生する条件・修正案**」を数文でまとめる簡潔な形式に変更
- 管理者がリポジトリごとに **Quick / Standard / Deep** の3段階から深さを選べる（既定はStandard）
- 管理者が機能を有効化してGitHub Appを入れるだけで、以降は新しいPRに自動でレビューが付き、開発者側の設定は不要
- 対象のEnterprise組織は、少なくとも1万ドル分のCode Reviewクレジットを2027年1月15日まで請求可能

### トピック2: Next.jsが臨時セキュリティ更新、認証不要のRCE 2件を修正
📅 2026年10月14日公開（出典: Next.js公式ブログ、The Hacker News）

Vercelは**Next.js 16.4.1（Active LTS）と15.5.28（Maintenance LTS）**を臨時セキュリティ更新として公開しました。9月の定例リリースから**上流ライブラリの対応待ちで延期されていた2件**を修正しています。

- **Critical: `use cache` 関数のRCE**（GHSA-673q-mjm6-r5xr、React側の関連アドバイザリあり）: Cache Componentsを使うApp Routerで、`use cache` 関数が複数の型付き配列を返すと、**認証なしでリモートコード実行**の恐れ。**回避策はない**ため、同じような関数がなくても即時更新が推奨
- **Critical: 画像最適化APIでのSVG処理のRCE**（CVE-2026-96889）: **glibc系Linux**で動作する場合が対象。回避策は **sharp 0.35.5以上**にすること
- **High: Server ActionsのDoS**（GHSA-p3m5-59mp-jv5r）: Server Actionsを1つ以上持つApp Routerアプリで、細工したリクエストによりCPUを占有される。Pages RouterやServer Actions未使用のアプリは影響なし

### 💻 トピック3: .NETのSDKをまとめて管理する「dotnetup」がプレビュー公開
📅 2026年10月15日公開（出典: .NET Blog、Publickey）

マイクロソフトは、.NETのSDKとランタイムを管理する**rustup風のツールチェーンマネージャ「dotnetup」**のプレビューを公開しました。

- **管理者権限が不要**で、ファイルはユーザーのフォルダに置かれる
- **複数バージョンを並べてインストール**でき、プレビュー版やデイリービルドも扱える
- `dotnetup init` / `list` / `update` / `sdk install preview` など、**OSによらず同じコマンド**で操作
- 特定のバージョンではなくメジャーバージョンや機能バンドを追跡し、**毎月の更新を取り込む**
- 既存の **`global.json` と連携**し、チームのビルドを再現しやすくする
- 現時点の対象はmacOS・Linuxのユーザー単位のインストール。**Windowsのシステム全体のインストール管理やワークロード管理は未対応**で、GitHub Actions等への統合も今後の予定

## まとめ

- **AIコードレビュー**は、速度と指摘の簡潔さが実用レベルに近づき、リポジトリごとに深さを選ぶ運用ができるようになりました。
- **Next.js**は回避策のないCritical脆弱性を含むため、**16.4.1 / 15.5.28への即時更新**が必要です。
- **dotnetup**により、.NETでもrustupのように**バージョンの切り替えや更新を1つのツールで**行えるようになりつつあります。
