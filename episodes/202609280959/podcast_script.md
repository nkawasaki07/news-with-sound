### トピック1: Dockerが「Cloud Sandboxes」を発表、AIエージェントの作業場をローカルとクラウドで往復可能に
📅 2026年9月28日公開（出典: Publickey｜Docker発表は9月24日）

Dockerが、AIエージェント向けの隔離環境をクラウドへ拡張する **Docker Cloud Sandboxes** を発表。ローカル版と同じ **マイクロVMベースの分離**、同じCLIのまま、Docker管理のコンピュートを常時利用できる。

最大の目玉は **稼働中のサンドボックスを止めずに移せるライブマイグレーション**。ファイルシステムをキャプチャし、移動先で再現することで動作を中断しない。起動は数百ミリ秒レベル。

狙いは2つの制約の解消で、**数時間かかるエージェント作業のあいだマシンを起動し続ける必要がなくなる**点と、**サブエージェントを大量に並列実行する際にローカルのハード性能に縛られなくなる**点。

料金は従量課金。最小の「Micro」（1 vCPU / 2GB RAM）が **$0.07/時（約10円）**、最大の「XL」（16 vCPU / 32GB RAM）が **$1.12/時（約168円）**。新規アカウントには**$250の無料クレジット**が付く。

### トピック2: Poimandres、Web向け数学ライブラリ「math」v0.1.0を公開
📅 2026年9月25日公開（出典: gihyo.jp）

three.js系ライブラリ群で知られる **Poimandres（pmndrs）** が、JavaScript/TypeScript向け数学ライブラリ **math v0.1.0** を公開。**レンダリング方式に依存しない**独立ライブラリで、WebGL・WebGPUのどちらでも使える。

カバー範囲は広く、**ベクトル/行列演算、回転用のクォータニオン、図形の交差判定、多角形の三角形分割、イージングとスプリングアニメーション、乱数とノイズ生成、色空間変換、逆運動学（IK）** までを一式で提供する。

設計の中心は速度で、**allocation-free（アロケーションなし）かつmonomorphic** を掲げる。計算ごとに新しい配列を返すのではなく **呼び出し側が渡した配列へ結果を書き込む** ため、メモリ確保のオーバーヘッドを削減できる。毎フレーム計算が走るゲームや物理・経路探索で効く設計。

API は `math/shapes`・`math/geometry`・`math/time`・`math/random`・`math/noise`・`math/color`・`math/ik` と**名前空間ごとにモジュール分割**され、個別インポートと **tree-shaking** に対応。AIコーディングエージェント向けのスキルも同梱されている。

### 🔒 トピック3: 改ざんされたGitHub Actionsが再有効化で「Mini Shai-Hulud」を再実行
📅 2026年9月25日公開（出典: The Hacker News）

5月に侵害され停止されていた2つのGitHub Actionsリポジトリが **9月16日に再有効化された際、悪意あるコードが残ったまま自動実行された**。攻撃者の新たな操作は一切不要だった。

対象は **actions-cool/issues-helper** と **actions-cool/maintain-one-comment**。侵害は **5月18日**、リリースタグに認証情報窃取のペイロードが仕込まれていた。

根本原因は **再有効化の前にリリースタグが掃除されなかった**こと。タグは5月18日の悪意ある内容を指し続けており、**`v2.2.1` のような可変バージョンタグで参照していたワークフローは再びペイロードをダウンロードして実行**した。npmを狙った **Mini Shai-Hulud** キャンペーンと関連する。

対応は、該当アクションの削除と **5月18日より前のクリーンなコミットSHAへのピン留め**、**流出した可能性のあるシークレットのローテーション**、ワークフロー実行履歴の確認、**9月16日以降の想定外コミットの監査**。今後は可変タグではなく **SHAピンニング** を原則とすべき事例。

### 🔒 トピック4: Cloudflare、Containersのクロステナント残留ディスク露出を修正
📅 2026年9月24日公開（出典: Cloudflare Blog）

Cloudflareが、Containersで **他の顧客のワークロードが残したディスクデータを読み取れてしまう脆弱性** を修正したと公表した。

原因は Linux の device mapper シンプロビジョニング（dm-thin）で **`skip_block_zeroing` が有効**になっていたこと。ブロックがコンテナ間で再割り当てされる際に**ゼロ埋めが行われず**、部分書き込みのあと読み出すことで **前の所有者のデータ**に到達できた。

露出しうる内容は、**ファイルシステムのメタデータ、ディレクトリ構造、データベースのページ、アプリケーションデータ**といった残留データ。Workers Paidアカウントがあれば、**同じホスト上で以前動いていたコンテナのデータを回収し得た**。

発見は研究者 Oren Yomtov 氏（Accomplish）で、**報告は9月4日**、**9月19日にフリート全体のクリーンアップまで完了**と**9日間**で収束。調査では **4大陸にわたり24配置のうち18、22ノードのうち20** で痕跡が確認された。修正は `skip_block_zeroing` の削除と、緩和前のディスク・キャッシュ層の全面廃棄。

## まとめ

本日は4本。**Docker Cloud Sandboxes** はAIエージェントの実行環境をローカルからクラウドへ連続的に広げ、長時間タスクと大量サブエージェントという2つの現実的な壁を取り払った。**Poimandres math** は、描画基盤に依存しない「速い計算」の土台をWeb側に用意した。

セキュリティの2本は、いずれも**自分のコードの外側**が起点だ。GitHub Actionsの件は **可変タグへの依存**という一点が再侵害を許した典型で、対策は SHAピンニングとシークレットのローテーションに尽きる。Cloudflareの件は、**自分では見えない共有インフラの下層**にもリスクが潜むことを示した一方、報告から9日での全面収束という対応速度も記録された。

依存先の固定方法を見直すこと、そして使っているマネージドサービスの障害・脆弱性報告を追うこと。どちらも今日から着手できる。
