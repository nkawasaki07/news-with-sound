### トピック1: GitHub Copilot Fusionが一般提供に
📅 2026年10月28日公開（出典: GitHub Universe 2026発表、gihyo.jp、labmemo）

タスクごとに**AIモデルの選択と組み合わせを自動で行う「Copilot Fusion」**が正式提供（GA）に。研究プレビュー「HydraFusion」の後継で、**全Copilotプラン**が対象です。

- 対応環境: **VS Code、Copilotアプリ、Copilot CLI、JetBrains IDE**
- 努力レベル: **Standard / High / Max** の3段階
- 実行パターン: 単一モデルの**Single**、判定役が下書きを検査して強いモデルへ引き継ぐ**Cascade**、複数モデルで批評し合う**Critique**
- 料金: Fusion自体の追加料金はなく、**使われたモデルの標準レートで従量課金**（High/Maxは消費が増える場合あり）
- 管理者は候補モデルの範囲や既定モデルを設定可能。HydraFusionの設定は自動移行

※「最上位モデルに迫る性能を約半額で」という主張はGitHub自身の発表値です。

### トピック2: Next.jsがバンドル削減用エージェントスキル「next-bundle-optimizer」を公開
📅 2026年10月28日公開（出典: Next.js公式ブログ）

AIエージェントに**JavaScriptバンドルの最適化**を任せるスキルが登場。**Next.js 16.4以降・Turbopack**が前提です。

- 導入: `npx skills add vercel/next.js --skill next-bundle-optimizer` → エージェントで `/next-bundle-optimizer`
- Turbopackの**モジュールグラフ**を解析し、`lazy()`で遅延したつもりが**別モジュールの静的importで先読みされている**ケースなどを検出
- RSCへの移動候補、**重複した大型依存**、**tree shakingが効かない箇所**も指摘
- 既定はレポートのみ、`fix` 指定で修正適用と再計測まで実行
- Vercelのv0とvercel.comで**合計約2MB（圧縮後）**を削減

人間向けの `next analyze` にも、**ルート別サイズ一覧・スナップショット比較・クリティカルレンダーパス表示**が追加されました。

### 🔒 トピック3: RustのZIPライブラリ「zip（zip2）」にCVSS 10.0の脆弱性 CVE-2026-115905
📅 2026年10月26日公開（出典: Wiz Vulnerability Database、セキュリティ対策Lab）

ZIPはファイル名を**ローカルファイルヘッダー（LFH）**と**中央ディレクトリ（CDFH）**の2か所に持ちます。このライブラリでは `ZipArchive` がCDFHを、`ZipStreamReader` がLFHだけを読むため、**検査では無害な名前に見えても展開時に別パスへ書き込める**パーサー不一致が発生します。

- 影響: **9.0.4までの全バージョン**
- 結果: **任意ファイル上書き → RCEのおそれ**
- 修正: **9.0.5以降**。ただし整合性チェック `enforce_header_consistency` は**オプトイン**なので有効化が必要
- 緩和策: LFHとCDFHで名前が食い違うZIPを拒否、展開処理をコンテナ等で隔離、検査と展開で別パーサーを使う構成を避ける

### 🔒 トピック4: Ivanti Connect Secureで悪用中のゼロデイ2件を追加修正
📅 2026年11月2日公開（出典: BleepingComputer）

10月に公表された認証バイパス **CVE-2026-104935** に続き、連鎖攻撃に使われていた2件が修正されました。

- **CVE-2026-111357**: 権限昇格
- **CVE-2026-118527**: 認証済み攻撃者による**ファイルアップロード**
- 少なくとも**10月初旬から悪用**。Volexityによると攻撃者UTA0576は**パッチ適用済み機器でも認証不要のroot実行**を達成し、**ログ改ざんでIntegrity Checker Toolを回避**
- インターネット公開のICSは**5,000台超**（Shadowserver）

修正版やCVSSは記事に記載がないため、**Ivantiのアドバイザリで直接確認**してください。

## まとめ

- **Copilot Fusion GA**: モデル選びをCopilotに任せる時代へ。ただし性能・コストの主張はGitHub自社発表
- **next-bundle-optimizer**: エージェントがモジュールグラフを読み、**遅延読み込みの抜け穴**を見つけて修正
- **zip2 CVE-2026-115905**: 9.0.5へ更新し、**整合性チェックの有効化**まで実施を
- **Ivanti ICS**: 新たな2件を含め**早急なパッチ適用**と侵害痕跡の確認を

AIに任せる範囲が広がるほど、依存ライブラリや機器の更新という足元の管理が重要になります。
