### トピック1: エージェント間通信の規格A2A、MCPと同じ財団のホストプロジェクトへ
📅 2026年08月19日公開（出典: Agentic AI Foundation / Techstrong.ai / Axios）

グーグル発のエージェント間通信プロトコル **Agent2Agent（A2A）** が、**Agentic AI Foundation（AAIF）のホストプロジェクト**になりました。AAIFは **MCP（Model Context Protocol）** を預かる団体で、これにより「**AIがツールを呼ぶ層＝MCP**」と「**AI同士が会話する層＝A2A**」の両方が、**同じベンダー中立の傘の下**にそろいました。

AAIFの参加組織は**2025年12月の発足時40社未満から250社超へ**拡大。A2A自体はGoogleが2025年4月に公開し、Linux Foundationへ寄贈、**v1.0仕様は2026年3月**に安定版化されています。

**実務上のポイント**: 複数エージェントを組み合わせる設計では、独自の連携グルーコードを書く前に **A2A / MCP で代替できる範囲**を洗い出しておくと、後々の移植コストが下がります。

### トピック2: WordPress 7.1「Mary Lou」がWordCamp USで公開
📅 2026年08月19日公開（出典: WordPress.org / The Repository / Gutenberg Times）

フェニックスで開催された **WordCamp US 2026 最終日**に、**WordPress 7.1「Mary Lou」** が公開されました。

- **目玉は「インタラクティブ状態のスタイリング」** — `:hover` / `:focus` / `:active` の見た目を、**CSSを書かずに管理画面UIから設定可能**に
- **デバイス別のレスポンシブスタイリング**に対応
- 新コアブロック2種: **Tabs** と **Playlist**（**波形ビジュアライゼーション付き**）
- **画像エディタを作り直し**、Notesに **@メンション**を追加してフィードバック機能として実用化

**開発者が要注意な変更**: **ブロックエディタがiframe内で動作**するようになったため、**古い自作ブロックは修正が必要**になる可能性があります。なお期待されていた**リアルタイム共同編集は今回見送り**。**800人超（うち初参加170人以上）** のコントリビューターが関わりました。

### 🔒 トピック3: Windows IKEのCVE-2026-33824、実環境で悪用されCISAがKEV追加
📅 2026年08月18日公開（出典: CISA / The Hacker News / BleepingComputer）

米CISAが**8月18日、実際に悪用が確認された脆弱性4件をKEV（Known Exploited Vulnerabilities）カタログに追加**しました。中でも重要なのが **CVE-2026-33824（CVSS 9.8）** です。

- **Microsoft Internet Key Exchange（IKE）Service Extensions の double free（二重解放）**
- **UDP 500番 / 4500番ポート**に細工したパケットを送るだけで、**権限を持たない攻撃者がリモートからコード実行可能**
- **サポート対象のWindows 10 / 11 / Server 全リリースが影響範囲**
- Palo Alto Networks **Unit 42** によれば、**中国語話者の攻撃者**がこの脆弱性を含む手動オペレーションを展開

**FCEB（米連邦民間行政機関）の修正期限は8月21日**（BOD 26-04）。修正パッチは提供済みのため、**VPN終端など境界に置いたWindowsから優先的に確認**を。

### 🔒 トピック4: VMware vCenterのパストラバーサルCVE-2026-59310を中国系APTが悪用
📅 2026年08月18日公開（出典: CISA / The Hacker News）

同じKEV追加分から、**Broadcom VMware vCenter の CVE-2026-59310（CVSS 9.8）**。**パストラバーサル**により、**vCenterにネットワーク到達できる攻撃者が任意コードを実行**できます。

- **中国が関与しているとみられるAPT**が悪用し、**バックドアと reverse_ssh バイナリ**を設置して永続的アクセスを確保
- 少なくとも1件では **Babuk派生のランサムウェア展開**にまで到達
- 被害は **47か国・361のユニークIP** で確認。内訳はドイツ55、米国41、トルコ38、イラン26、フランス25

**仮想基盤の管理サーバーは、陥落した時点で配下すべてを失う場所**です。**インターネットから直接到達できる状態になっていないか**、この機会に構成を見直しましょう。
