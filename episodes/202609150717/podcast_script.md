### トピック1: DeepSeekがV4.1-Flashを公開、画像認識をモデル本体に統合
📅 2026年9月10日公開（出典: THE BRIDGE / NOVAIST）

中国のDeepSeekが新モデル **DeepSeek-V4.1-Flash** を公開しました。総パラメータ数は **5,520億のMoE（専門家混合）** で、アーキテクチャは **Causal Encoder-Decoder（CED）** 構造の40層Transformer（causal encoder 20層＋decoder 20層）。

最大の特徴は**非対称なアクティブパラメータ設計**で、**入力処理時は80億、出力生成時は160億**と段階によって動かす範囲を変えます。コンテキスト長は**100万トークン**、最大出力は**38万4,000トークン**、通常モードと推論モードの双方に対応。

これまで別チェックポイントだった**画像理解がネイティブ統合**され、**API料金は値上げではなく引き下げ**。旧名 `deepseek-v4-flash` と `deepseek-v4-flash-vision-exp` は当面受け付けつつ、リクエストはV4.1-Flashへルーティングされます。

### トピック2: Safari 27公開、ESMローダーをC++で刷新しtop-level awaitが仕様完全準拠
📅 2026年9月15日公開（出典: Qiita プログラミング雑記 / Apple）

AppleがiOS/iPadOS 27とmacOS 27 Golden Gateを正式リリースし、あわせて**Safari 27**が公開されました。開発者に直結するのは **ECMAScriptモジュール（ESM）ローダーのC++による全面書き直し**です。

これにより **top-level await（モジュール最上位でのawait）が仕様に完全準拠**し、**初期化完了前に値を参照してしまうエラーが修正**されました。Chrome / Firefox との**モジュール実行順序の互換性が揃う**ため、ブラウザ差分を吸収する回避コードの必要性が減ります。

なおmacOS 27はIntel Macが非サポートとなり、インストーラーは過去最大の約18.4GBに達しています。

### 🛠 トピック3: AWS 9月第2週アップデート — Lambdaがタイムアウト90分・Graviton5対応
📅 2026年9月7日週（出典: Qiita プログラミング雑記 / AWS）

**Lambda Managed Instances** が新プロセッサ **Graviton5** に対応し、**タイムアウト上限が90分へ延長**されました。長時間バッチやエージェント実行を関数のまま任せられる範囲が広がります。

ストレージ側では **S3 Object Lock に「イベントホールド」** が追加され、**固定期間ではなくイベント起点の可変リテンション**が可能に。

AI基盤では **Amazon Bedrock で OpenAI GPT-6 Astra が一般提供開始**、インフラ面では **Amazon EVS が大阪リージョンへ展開**されました。

### 🛠 トピック4: DeNA、GrafanaダッシュボードのIaC化に挑戦
📅 2026年9月14日公開（出典: DeNA Engineering / Qiita プログラミング雑記）

GUIで手軽に作れる反面、**変更の追跡性が低く環境間で差分が発生しやすい**というGrafanaダッシュボードの課題に対し、DeNAが**IaC化の実践事例**を公開しました。

採用したのは **Grafana Foundation SDK の TypeScript版**。実データの調査とコード生成には **AIを活用**し、生成物は **CIで静的検証**、**Git Sync 経由で複数環境へ安全に配布**する構成です。

「作成の手軽さを保ったまま保守性を高める」という**現実的な落としどころ**が示されており、オブザーバビリティ基盤の運用設計として参考になります。
