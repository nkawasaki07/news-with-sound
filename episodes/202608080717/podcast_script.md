### トピック1: マイクロソフト、AIがトレースログを分析する「WPA MCP」をプレビュー公開
📅 2026年8月5日公開（出典: Publickey ／ Microsoft DevBlogs）

マイクロソフトが **Windows Performance Analyzer MCP（WPA MCP）** のアーリープレビューを発表しました。アプリが遅い原因の調査を、**自然言語でAIに依頼できる**ツールです。

従来はWindows全体のイベントトレース（ETW）を自力で読み解く必要があり、相応の知識と経験が要求されていました。今回は **WPAの画面にGitHub Copilot CLIを組み込む**ことで、プロンプトからトレース分析を実行できます。マイクロソフトが示したサンプルプロンプトでは、ハングアップ、入力の応答遅延、**CPUの枯渇・ディスクのボトルネック・メモリ負荷・ページング・サービス競合・問題のあるドライバー**といった観点を優先的に調べ、システム全体の問題か単一アプリの問題かを切り分けたレポートを生成させています。

### トピック2: npm代替のパッケージマネージャ「vlt」がバージョン1.0に到達
📅 2026年8月6日公開（出典: Publickey ／ vlt technology）

JavaScriptパッケージマネージャ **vlt（ボールト）が 1.0 に到達**し、npmのミラーレジストリおよびプライベートレジストリソフトウェア「vsr」の有料ホスティングも開始されました。

- **npmと同じコマンド体系**のドロップイン置き換え。既存ツールチェーンをそのまま利用可能
- vltレジストリはnpmレジストリとAPI互換のため、**yarn / deno / bun からも参照可能**
- **OSV** などの脆弱性データベースを参照し、不正なmanifestやマルウェアを含む **27万5000以上のパッケージを排除**
- エッジロケーション配信により、クリーンインストールが **npmレジストリ比で38%高速**
- 依存関係を**グラフ構造**として扱い、「特定の依存を持つパッケージを除外」等の高度な検索・フィルタリングに対応
- プライベートレジストリは **2GBまで無料**

### 🛠 トピック3: Pulumi CloudがTerraformステートバックエンドとしてGA、HCLをネイティブサポート
📅 2026年8月3日公開（出典: Pulumi Blog）

**今日のインフラ・DevOpsコーナー。** Pulumiが、**Pulumi CloudをTerraformのリモートステートバックエンドとして一般提供（GA）**したと発表しました。

- 既存の **Terraform / OpenTofu 資産**を、リモート実行・手動承認・アクセス制御つきで管理可能
- **HCLがPulumiのファーストクラスなIaC言語に**。OpenTofu互換として engine がネイティブサポート
- **Terraformモジュールをそのままインポート**でき、プライベートレジストリでのホストにも対応
- 言語の壁を越えてモジュールを共有できる **Terraformモジュールレジストリ**も提供

「PulumiはTypeScriptやPythonで書くもの」という前提が、この対応で大きく変わることになります。

### 🛠 トピック4: Terraform 1.16.0 beta2 公開、モジュール内で import ブロックが利用可能に
📅 2026年8月5日公開（出典: HashiCorp Terraform リリースノート）

同じくインフラの話題。**Terraform v1.16.0-beta2** が公開されました。

- **import ブロックがモジュール内でもサポート**。既存リソースの取り込みがモジュール単位で完結
- lifecycle ブロックが **`destroy = false`** に対応し、リソースの破棄そのものを禁止できる
- プロバイダーが **plan 時の private data を apply まで保持**できるように（`terraform_data` の `store` ブロック）
- リソースアクションのトリガーに **`on_failure` モード（halt / taint / continue）** を追加

※ 本バージョンは **ベータ（プレリリース）** であり、破壊的変更を含むマイナー更新として扱われています。
