### トピック1: JetBrainsが完全ローカル動作のコーディングエージェント「Junie Local」を提供開始
📅 2026年8月31日公開（出典: Publickey）

JetBrainsが、**完全にローカルマシン上だけで動作する**AIコーディングエージェント「Junie Local」の提供を開始しました。**API使用料・モデル使用料は一切不要で、ダウンロードも利用も無料**。コードが手元のマシンから出ないのが最大の特徴です。

採用モデルはアリババクラウドの **Qwen3.6-27B を4ビット量子化**したもので、エージェントハーネス・モデルパラメータ・推論エンジンまでスタック全体を最適化。社内テストでは**推論制限1万トークンのClaude Sonnet 4.5と同等**の能力とされ、GPT-5（ミディアム・エフォート）にはわずかに及ばなかったとのこと。

CLIで `/local` と入力するだけでクラウド版Junieから切り替えられ、`AGENTS.md` や `skill.md`、`guidelines.md` といった設定ファイルはそのまま有効です。無料であることから、**コスト面で控えていた大規模リファクタリングやテストカバレッジの穴埋め**に向くと説明されています。

動作環境は現時点で **M5プロセッサ＋64GBメモリのMac**。RTX5090搭載PCとDGX Sparkでも社内プロトタイプが稼働中で、24GBメモリのGPUへの対応も検討中です。

### トピック2: VS Code 1.135に「Rubber Duck」機能が実験的実装、別AIからセカンドオピニオン
📅 2026年9月2日公開（出典: Publickey）

Visual Studio Code の最新版 **1.135** に、開発中のAIエージェントの仕事について**別のAIモデルにセカンドオピニオンを求める**「Rubber Duck」機能が実験的に実装されました。

狙いは明確です。**同一のAIモデルに自己レビューさせても同じバイアスで判断してしまう**ため見落としが残る。計画段階のミスが実装・テストの後工程で発覚すると手戻りが大きくなる、という問題への対処です。名称は、プログラマがアヒルのおもちゃに説明することで思考を整理し問題を発見する古典的手法に由来します。

利用は Copilot Agent Host のセッションで **`/rubber-duck` コマンドを入力するだけ**。もともと2026年4月に GitHub Copilot CLI で実験実装されたものが、エディタ側に降りてきた形です。

なお8月にリリースされた 1.132〜1.135 の4リリースでは、**Markdownハイブリッドエディタの差分表示**、統合ブラウザ内でのWebページへのコメント、**ローカルHTMLファイルの自動ホットリロード**なども追加されています。

### トピック3: Firefox 155正式リリース、CSS `attr()` が全プロパティで利用可能に
📅 2026年9月1日リリース（出典: MDN Web Docs / Mozilla）

Firefox 155 が正式リリースされました。Web開発者向けの目玉は **CSS `attr()` 関数の全面解禁**です。これまで `content` プロパティ内でしか使えなかった `attr()` が、**任意のCSSプロパティで使用可能**になりました。

`width: attr(data-size px)` のように書けば、**JavaScriptを使わずにHTML属性の値でスタイルを駆動**できます。`px` や `s` といった単位識別子、フォールバック値、名前空間つき属性にも対応し、**コンテナスタイルクエリの内部**でも利用できます。

CSSではこのほか、開始値と終了値の間の進捗を `<number>` で返す **`progress()` 関数**（例: `opacity: calc(0.4 + progress(100cqw, 300px, 900px) * 0.6)`）、色の**アルファ値だけを差し替える `alpha()` 関数**が新たにサポート。`font-stretch` は **`font-width` に改名**され、旧名はレガシーエイリアスとして残ります。

JavaScript側では TC39 の await dictionary プロポーザルに基づく **`Promise.allKeyed()` / `Promise.allSettledKeyed()`** が追加。イテラブルではなく**オブジェクトでPromiseを受け取り、結果も同じキー名で読み出せる**ようになりました。さらに WebAssembly では wide arithmetic プロポーザル（`i64.mul_wide_s` など128ビット演算）と compact import section に対応しています。

### 💻 トピック4: Python 3.15 の最終リリース候補 3.15.0rc2 が公開
📅 2026年9月1日公開（出典: Python.org）

**今日のプログラミング言語コーナーです。** Python 3.15 の**最終リリース候補**となる 3.15.0rc2 が公開されました。rc1 以降、**76名のコントリビューターによる約144件**のバグ修正・ビルド改善・ドキュメント更新が含まれます。

重要なのは、**ここから先 3.15 系列で ABI 変更は入らない**と明言された点。開発チームはサードパーティライブラリの保守者に対し、**いま 3.15 対応の wheel をビルドして PyPI で公開してほしい**と呼びかけています。リリース候補向けにビルドしたバイナリwheelは**正式版 3.15 でもそのまま動作する**とのことです。

3.15 の主な新機能は以下のとおり。

- **PEP 810**: 起動時間短縮のための**明示的な遅延インポート**
- **PEP 814 / PEP 661**: 組み込み型 **`frozendict`** と **`sentinel`** の追加
- **PEP 798**: **内包表記の中でのアンパック**
- **PEP 686**: **デフォルトエンコーディングが UTF-8 に**
- **PEP 799**: 専用のプロファイリングパッケージと高頻度サンプリングプロファイラ「Tachyon」
- **PEP 803/820/793**: **フリースレッドビルド向けの安定ABI**（macOS公式バイナリはフリースレッド対応をデフォルト導入）
- **JITコンパイラの大幅強化**: x86-64 Linux で標準インタプリタ比 **幾何平均8〜9%高速化**、AArch64 macOS ではテールコールインタプリタ比 **12〜13%高速化**

**正式版 3.15.0 のリリースは2026年10月1日の予定**です。なお本リリース候補はプレビュー版であり、本番環境での利用は推奨されていません。

## まとめ

本日の4本を貫くキーワードは**「ローカル実行」と「検証」**でした。

Junie Local は**コードを外部に出さずにエージェントを回す**方向、VS Code の Rubber Duck は**単一モデルの判断を鵜呑みにしない**方向。どちらも「AIを使う側がどう統制を取り戻すか」という同じ問題意識の裏表と見ることもできます。ただし前者はモデル性能とハードウェア要件（M5 Mac＋64GB）というトレードオフを、後者は複数モデルを回すコストを抱えている点は押さえておきたいところです。

一方で Firefox 155 と Python 3.15rc2 は、地に足のついた**言語とプラットフォームの進化**。特に `attr()` の全面解禁は、これまでJavaScriptに頼っていた「属性値からスタイルを組み立てる」パターンをCSSだけで書き直せる可能性があります。ただし現時点ではFirefoxでの対応であり、**他ブラウザの実装状況を確認してから本番投入を判断すべき**でしょう。

Python 3.15 正式版は10月1日。依存ライブラリの 3.15 対応状況を、いまのうちに棚卸ししておくことをおすすめします。
