### トピック2: Svelteの9月アップデート、SvelteKit 3がリリース候補に到達
📅 2026年9月1日公開（出典: Svelte公式ブログ）

Svelte公式ブログの月次アップデート。最大の見どころは**SvelteKit 3がRC（リリース候補）に到達**したことです。

- **設定ファイルの統合**: SvelteKitの設定を `vite.config.js` に直接記述可能に。`svelte.config.js` を省略でき、**SvelteKit 3ではこちらが正式な置き場所になる見込み**
- **明示的な環境変数**: `$env/*` の宣言と型付けを**一箇所にまとめて記述**できる仕組みのプレビュー
- **パスエイリアスの変更**: 新規プロジェクトは `$lib` ではなく **`#lib`（Node subpath imports）** を使用
- **vite-plugin-svelte**: `dynamicCompileOptions` 引数が追加され、client / server / SSR で**環境ごとに異なるコンパイル設定**が可能に
- **移行支援**: `sv` CLI に `ai-tools` アドオンと、既存アプリ向けの **`sveltekit-3` 移行タスク**を同梱

### 📱 トピック3: Google Playが8月31日からAndroid 16（API 36）ターゲットを必須化
📅 2026年8月31日発効（出典: Android Developers / 各種開発者向け解説）

**8月31日**からGoogle PlayのターゲットAPIレベル要件が切り替わりました。**Android 16（API level 36）以上をターゲットにしていないアプリは、アップデートを公開できません**。新規アプリの登録も同様です。

**必要な対応**

- ビルド設定の **`compileSdk` / `targetSdk` を 36 に更新**
- 課金機能利用時は **Play Billing Library を 8.0.0 以降**へ
- サードパーティSDKの互換性確認と、**Android 16実機でのテスト**

**猶予措置と影響**

- 条件を満たす開発者は Play Console から**一度だけ延長申請**が可能。承認されれば期限は**11月1日**まで
- 未対応でも既存ユーザーの端末からアプリが消えるわけではないが、**Android 16以降の端末では新規インストール時に検索結果へ出なくなる**
