### トピック1: GitHub Copilot コードレビュー、エージェントスキルとMCPがGA
📅 2026年7月29日公開（出典: GitHub Changelog）

GitHubがCopilotのコードレビュー機能で、**エージェントスキル**と**MCPサーバー連携**をパブリックプレビューから**一般提供（GA）**へ昇格させた。対象はCopilot Pro / Pro+ / Business / Enterprise の全ユーザー。

- **エージェントスキル**: リポジトリの `.github/skills` 配下にスキル用ディレクトリを作り `SKILL.md` を置くと、レビュー時にチーム独自のコーディング規約や社内ツールを呼び出せる
- **MCPサーバー接続**: 課題管理システムやドキュメント基盤などの外部コンテキストをレビューに取り込む。**MCP経由のツール呼び出しは読み取り専用に限定**
- Copilot cloud agent向けに設定済みのMCP構成は**自動的にコードレビューへ適用**され、GitHub MCPとPlaywright MCPは既定でオン
- **新機能**: コメントがスキル由来かMCP由来かを示す**出典表示（attribution）**が追加

### トピック2: Chrome 152ベータ、CPU Performance APIと擬似要素の拡張
📅 2026年7月30日公開（出典: Chrome for Developers）

Chrome 152のベータ版が公開。Web標準まわりで実装に直結する追加が並んだ。

- **CPU Performance API**: 端末のCPU性能を**1〜4の性能ティア（0は不明）**として取得できる。Compute Pressure APIと組み合わせ、非力な端末には軽量なページを配信するといった出し分けが可能に
  - 一方で**フィンガープリンティングの精度が上がる懸念**があり、利用者はChromeのパフォーマンス設定で値を上書きできる。管理者向けには `CpuPerformanceTierOverride` ポリシーも用意
- **CSSPseudoElementの対応拡大**: `::backdrop` と `::view-transition` に対応。ビュー遷移を**アニメーション途中で割り込んで新しい遷移を開始**する際、現在アニメーション中の座標を引き継いで**視覚的なジャンプを防ぐ**
- **HTMLの `autocorrect` 属性**: `<input>` / `<textarea>` / contenteditable で自動修正の有無を制御
- **`app-region` CSSプロパティ**の標準化（値を `move` / `none` に整理し、継承挙動を明示）

### 💻 トピック3: PHP 8.6.0 Alpha 3公開、部分適用とclamp()が前進
📅 2026年7月28日公開（出典: php.net アナウンス）

PHP開発チームが**7月28日にphp-srcで3件のリリースをタグ付け**し、**PHP 8.6.0alpha3**を公開。同時に**8.5.9**と**8.2.33**のセキュリティ更新も出た。

- **8.6系の目玉**
  - **部分適用（partial function application）**: 引数の一部だけを束縛した新しい関数をその場で生成できる。コールバック記述の省力化に効く
  - **`clamp()` 関数**: 値を上限・下限の範囲に丸める組み込み関数
  - **Windows版でのTAILCALL VMサポート**
- **全アクティブブランチ共通のセキュリティ修正**
  - `ext/bcmath` のスタックベース領域外書き込み
  - pgsql拡張でのバックスラッシュを悪用した**SQLインジェクション**
  - Pharの循環シンボリックリンクによるクラッシュ
  - libgd由来の脆弱性
- 次のマイルストーンは**Beta 1、2026年8月13日予定**
