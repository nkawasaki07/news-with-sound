### トピック1: Anthropic、Claude Fable 5.2とMythos 5.2を公開
📅 2026年11月9日公開（出典: Claude Platform Docs、The Next Web）

Anthropicが新フラッグシップの **Claude Fable 5.2** と **Claude Mythos 5.2** を公開しました。

- モデルID: `claude-fable-5-2` ／ `claude-mythos-5-2`
- **コンテキスト100万トークン**、最大出力12.8万トークン、適応的思考は常時オン（effortは low〜max の5段階、既定は high）

**移行時の注意（破壊的変更）**:

### トピック2: Vite開発サーバーに深刻なリモートコード実行の脆弱性
📅 2026年11月10日公開（出典: Vite GitHub Security Advisory、JavaScript Weekly）

Viteで **深刻度Critical（CVSS v4 9.1）** の脆弱性（GHSA-p4f5-76q4-ffq7）が公開されました。

- リゾルバーが、URL由来のモジュールIDを **エスケープせずに** 仮想モジュール `__vite-browser-external` などへ埋め込んでいた
- 細工したリクエストでコードを注入でき、**`server.fs`制限を回避したファイル読み取り** や **開発サーバー上での任意コード実行** につながる
- 条件は、`--host` や `server.host` で **開発サーバーをネットワークに公開している場合**
- 修正版: **vite 8.3.7 / 8.2.5 / 8.1.7 / 7.3.8 / 6.4.6**、vite-plus 1.5.1

共有の開発環境やLAN上でViteを動かしている場合は、**すぐに更新**しましょう。

### 📱 トピック3: .NET MAUI 11が正式版に、全プラットフォームでCoreCLRに統一
📅 2026年11月11日公開（出典: Publickey）

.NET 11と同時に **.NET MAUI 11** が正式リリースされました。7月のプレビュー時点で予告されていた変更が、正式版で確定した形です。

- iOS・Android・Mac Catalystで使われていた **Xamarin由来のMonoランタイムを廃止**し、**CoreCLRに統一**
- モバイルでも **段階的JIT、ReadyToRun（事前コンパイル）、PGO（プロファイルに基づく最適化）** が使える
- iOS／Mac Catalystで必要なNative AOTのツールチェーンも統一。AndroidのAOT対応も予定
- マイクロソフトによると、iOS・Mac Catalystは **おおむね高速化**、Androidの起動時間とアプリサイズの変化は **10%以内**

ランタイムが変わるため、**移行前の互換性確認**が推奨されています。
