### トピック1: MCPの新仕様「2026-07-28」でステートレス通信が正式仕様に
📅 2026年7月27日公開（出典: Publickey）

AIツールとサービスを接続する事実上の業界標準プロトコル **MCP（Model Context Protocol）** の新仕様が本日公開される見通しです。最大の変更点は**ステートレス通信への移行**。従来必要だった初期化ハンドシェイクと `Mcp-Session-Id` ヘッダによるセッション管理が廃止され、**クライアントのリクエストがどのMCPサーバに到達しても処理できる**ようになります。結果として、**複数台のMCPサーバ＋ロードバランサーによるスケーラブルな運用**が容易になります。GitHubも同日7月28日に新仕様対応の次期GitHub MCPサーバをリリースすると発表済みで、セッションIDのDB読み書きが不要になることで**接続がシンプル・高速化**するとしています。なお Tier 1 SDK では**後方互換性は維持**されます。

### トピック2: Rustで書き直されたBun、正式リリース前にClaude Codeへ本番投入か
📅 2026年7月21日公開（出典: Publickey）

JavaScriptランタイム **Bun** は、AIエージェントを用いて **Zig から Rust へわずか11日間で移植**されたことで話題になりましたが、その Rust 版が**7月17日リリースの Claude Code v2.1.181 の内部ですでに稼働している模様**です。指摘したのは Python Software Foundation 理事の Simon Willison 氏。根拠は2点で、アプリ内部に**次期版を示す「Bun v1.4.0 (macOS arm64)」の文字列**が見つかること、そして **`.rs` で終わる Rust コードへの参照が多数存在**すること。Bun 開発者の Jarred Sumner 氏もこの投稿をリポストしており、事実上の追認とみられます。**大規模ソフトウェアのAIによる言語移植が実プロダクトで動いている実例**といえます。

### 🛠 トピック3: AWS CloudFormationに「Expressモード」登場、デプロイ最大4倍速
📅 2026年7月21日公開（出典: Publickey／AWS）

AWSが、IaCツール CloudFormation の新機能 **「Express モード」** の提供を開始しました。仕組みはシンプルで、**リソースが安定状態になるまでの待機を行わず、設定適用時点で処理を完了**させます。AWSが示す実測例では、**DLQ付きSQSキューの作成が標準モード64秒 → Expressモード最長10秒**、**ネットワークインターフェース付きLambda関数の削除が20〜30分 → 最長10秒**。開発中の**反復的なインフラ構成変更**、コンポーネントのテスト、そして**AIエージェントによる高速なインフラ操作**など、「最終的にインフラが安定すればよい」ユースケースで効果を発揮するとしています。

### 🛠 トピック4: Grafana、OpenTelemetry Collectorの設定をGitHub Actionで同期可能に
📅 2026年7月21日公開（出典: Grafana Labs）

Grafana Labs が、構成管理機能 **Fleet Management における OpAMP サポートを一般提供（GA）** に切り替えました。OpAMPは**多数のエージェント設定をサーバ側から一元配布する**プロトコルです。あわせて、従来 Grafana Alloy 向けだった同期用 **GitHub Action が OpenTelemetry Collector のパイプライン設定にも対応**。これにより、**Collector の設定をGitリポジトリで管理し、マージをトリガーに稼働中のエージェントへ自動反映する GitOps 運用**が可能になります。監視・オブザーバビリティの設定が**コードレビュー可能な資産**になる点が実務上の利点です。
