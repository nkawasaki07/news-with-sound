### トピック1: Deno開発チーム、AIとの対話でネイティブアプリを作る「Dactyl」を発表
📅 2026年8月25日公開（出典: gihyo.jp／発表は8月23日）

Node.js・Denoの生みの親であるRyan Dahl氏らのチームが、バイブコーディングプラットフォーム **Dactyl** を発表しました。ブラウザ上で作りたいアプリを文章で説明すると、AIエージェントが **SwiftUI** でコードを書いてネイティブアプリを構築します。

最大の特徴は **SwiftUIレンダラーをWASMで実装したデバイスシミュレーター**で、**MacもXcodeも不要**でブラウザ内に低遅延プレビューが出ます。同一のSwiftUIコードから **WebViewを介さずAndroidのネイティブAPKへコンパイル**でき、カメラ・地図・GPSなど実デバイス機能も利用可能。基盤は **Cloudflare Durable Objects** 上。無料プランでもiOSプレビューと月100クレジットまで試せます。

### トピック2: Claudeの脆弱性スキャンが最上位セキュリティモデル「Mythos 5」へ
📅 2026年8月24日公開（出典: gihyo.jp／発表は8月21日）

Anthropicが、エンタープライズ向け機能 **Claude Security** のスキャンモデルを **Claude Mythos 5** に切り替え、パブリックベータで提供開始しました。コードベースを走査して脆弱性を検出し、**レビュー用のパッチ案まで提示**します。**ファイルをまたぐデータフローを追跡**するため、従来型スキャナが見逃す複合的な脆弱性パターンも拾えるとしています。

注目は提供設計です。Mythos 5は攻撃にも転用しうる能力を持つため直接アクセスは慎重に制限し、**パッチやアラートといった出力のみを返す形にすることでリスクを抑える**という考え方が取られています。あわせて、OSSのセキュリティ改善に **3,500万ドル相当のクレジット**を提供する「Defender Advantage Fund」の設立も発表されました。

### トピック3: Next.js 16.3正式リリース ─ Turbopackのメモリ最大90%減
📅 2026年8月26日公開（出典: Publickey）

VercelがReactベースのフレームワーク **Next.js 16.3** を正式リリースしました。中心は性能改善です。

- **Turbopack**: ファイルシステムキャッシュとキャッシュ解放の改善で、**開発時メモリ使用量が最大90%削減**、**再ビルドは最大5.5倍高速化**

- **SSR**: 内部の Web Streams API を **Node.jsネイティブのStream API** に変更し、変換処理を省いて**高負荷時に最大22%高速化**
- **Instant Navigations**: ローディングUIの即時表示＋残りのストリーミング、レンダリング済みUIのキャッシュ再利用で、**SSRでもSPA並みの遷移**を実現。遅い箇所を検知する Instant Insights も同梱

### 💻 トピック4: Mojoがオープンソース化 ─ コンパイラとツールチェーンをApache 2.0で公開
📅 2026年8月20日公開（出典: Publickey／発表は8月18日 ModCon 2026）

Pythonライクな高速言語 **Mojo** の開発元Modularが、自社イベント ModCon 2026 で **Mojoのオープンソース化**を発表。**コンパイラ・ツールチェーン、推論ライブラリMAX** が **Apache 2.0** でGitHubに公開されました。バージョン1.0到達時に表明していた計画が、前倒しで実現した形です。

Mojoが狙うのは2点。**インタプリタ由来のPythonの遅さをコンパイル言語として解消**すること、そして **特定ベンダーのGPUに依存せず** GPU/TPU/NPU/アクセラレータの性能を引き出すことです。さらに **マイクロソフトとの協業によるWindows版**の開発も表明されました（時期未定）。なお同社は2026年6月にクアルコムに買収されており、アーキテクチャ非依存の方針は同社のAIデータセンター戦略とも整合します。
