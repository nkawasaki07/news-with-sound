### トピック1: OpenAI、全二重音声モデル「GPT-Live-1」をAPIで提供開始
📅 2026年9月10日公開（出典: OpenAI公式ブログ / unite.ai）

深い推論は後段のモデルに委譲する設計のため、**音声レイヤーと推論レイヤーを分けて組む**前提になります。

### トピック2: React 19.3リリース、ViewTransitionとFragment Refsが安定版に
📅 2026年9月9日公開（出典: React公式ブログ）

実験的扱いだった2つの主要機能が**安定版（stable）**へ昇格しました。

- **`<ViewTransition>`**: ブラウザの View Transition API をReactから利用。要素を囲むだけで**出現・退場・移動・リサイズのアニメーション**をReactが処理、Suspenseとの連携も容易に
- **Fragment Refs**: Fragment に直接 ref を渡せるようになり、**ラッパー用の余計な `<div>` なしで**兄弟要素群へイベントリスナー・フォーカス制御・IntersectionObserver/ResizeObserver を適用可能
- **`browser()` API**: そのコンポーネントを**サーバーでレンダリングせずブラウザを待つ**指定が可能に
- **Trusted Types 対応**によるDOM挿入まわりのセキュリティ強化、**Server Components での Context 利用**、フルスクリーンイベント・フォーム・フォーカス関連のバグ修正

### 🛠 トピック3: Amazon Linux 2027がパブリックプレビュー、SELinuxが既定で強制モードに
📅 2026年9月9日公開（出典: Publickey / AWS What's New）

AWSが**4年ぶりのメジャーバージョンアップ**となる Amazon Linux 2027 をパブリックプレビュー公開しました。

- 最大の変更は **SELinuxが既定でエンフォーシング（強制）モード**に。現行の Amazon Linux 2023 は記録のみのパーミッシブモードが既定だったため、**管理者権限でもポリシー違反のアクセスは拒否**される
- ベースは **Fedora 44 / 45 の一部**だが、Fedora派生ではなくAWS独自のリリースサイクルとサポートを提供
- **カーネルは 7.1 以上**、パッケージ管理は引き続き RPM と dnf
- AI/MLワークロード向けに **Trainium / Inferentia を制御する AWS Neuron ドライバー**を含むアクセラレータ用カーネルドライバーを同梱
- 対象アーキテクチャは **x86-64 と ARM**。現行の Amazon Linux 2023 は **2029年6月30日までサポート**予定

既存の運用スクリプトやコンテナがSELinux強制モード下で動くかは、**プレビュー期間中の検証項目**になります。

### 🛠 トピック4: GitHub Actionsの「cache-mode」が全プランでGA、キャッシュ権限を最小化
📅 2026年9月10日公開（出典: GitHub Changelog）

GitHub Actions のキャッシュアクセスを**ワークフロー単位・ジョブ単位で最小権限に制御**できる cache-mode が一般提供となりました。

指定できるアクセスレベルは4種類:

| モード | 復元(restore) | 保存(save) | 既定となるケース |
|---|---|---|---|
| `read` | ✅ | ❌ | `pull_request_target` など低信頼イベント |
| `write` | ✅ | ✅ | `push` など信頼されたイベント |
| `write-only` | ❌ | ✅ | — |
| `none` | ❌ | ❌ | — |

- 狙いは**キャッシュポイズニング（汚染されたキャッシュの読み込み）の防止**
- **ジョブ単位の設定がワークフロー単位を上書き**し、モードはキャッシュサービス側で強制される
- **再利用可能ワークフローでは、呼び出された側が呼び出し元より強い権限を持てない**
