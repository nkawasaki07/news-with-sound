### トピック1: Google、開発と脆弱性対策に強い「Gemini 4 Carbon」を発表
📅 2026年10月29日公開（出典: gihyo.jp、The Hacker News／Google発表は10月28日）

10月に提供が始まった **Gemini 4 Argon をベースに、長時間のコーディング作業と、脆弱性の発見から修正までを強化**したモデルです。

- 社内テストでは、**根拠のない主張がArgonの約半分**に減少
- **Terminal-Bench 4.0 で 65.2%**（Argon 57.1%、GPT-6 Astra 59.1%、Claude Opus 5.5 59.6%）
- SEC-bench Pro での脆弱性発見は 88.2%、CWE-bench v1 での修正は 71.0%（ガードレールを外した条件）
- **まずはサイバー防御を担う審査済みパートナーに先行提供**（Fairwind Program）。開発者向けの一般提供はその後
- 導入期間中の価格は **100万トークンあたり入力$2・出力$10**（期間後は$4／$20）

※ ベンチマークの一部はGoogleの社内測定です。

### トピック2: Node.js 26 が LTS「Lithium」に
📅 2026年10月29日公開（出典: gihyo.jp／リリースは10月28日）

**Node.js 26.13.0** の公開で、26系が**長期サポート（LTS）に移行**しました。

- コードネームは **Lithium**、サポートは **2029年4月末まで**
- 今回の変更は **LTSを示すメタデータの更新だけ**で、機能は 26.12.1 と同じ
- **注意点:** Node.js 25 以降の Linux 向けバイナリは **libatomic に依存**。24 以前から移行する場合、ディストリビューションによっては追加インストールが必要
- Node.js 27 以降は**メジャーリリースが年1回となり、すべてLTS**になる予定。26 は旧方式で最後のLTS

### 🔒 トピック3: Linuxカーネルにリモートから狙えるTCPの脆弱性 CVE-2026-98432
📅 2026年10月29日公開（出典: The Hacker News）

**IPv4のTCP接続を確立する処理の競合状態**により、解放済みのメモリを使ってしまう**ユースアフターフリー**が起きる脆弱性です。Linux 4.4 から存在し、IPv6 は影響を受けません。

- 深刻度は**評価が割れている**: カーネルCNAは **CVSS 9.8**、Red Hat は 8.1（Important）、Amazon は 7.0
- **Anthropicは、Claudeでマルチパス TCP（MPTCP）を待ち受けるサーバーのroot権限を奪う攻撃コードを作れた**と10月27日に報告（コードは非公開）
- **10月29日時点で実際の攻撃は確認されていない**
- 修正済みの上流版: 5.10.272 / 5.15.223 / 6.1.190 / 6.6.159 / 6.12.113 / 6.18.56 / 7.2.10 / 7.3
- Debian、Oracle Linux、Amazon Linux 2023（一部）、SUSE の一部は修正済み。**Ubuntu・RHEL・Amazon Linux 2 などは修正待ち**
- Red Hat は、条件を満たす緩和策は**現時点でない**としています

### 🔒 トピック4: Giteeの公開リポジトリから有効なクラウド・AI認証情報 2万6400件
📅 2026年10月29日公開（出典: The Hacker News）

独立研究者 Ben Zimmermann 氏が、中国のコード共有サービス **Gitee の公開リポジトリ約725万件**を TruffleHog と Kingfisher で調べ、**実際に使える認証情報を 2万6400件**見つけました。

- 内訳: **Alibaba Cloud AccessKey 9,473件**、YouTube（Google Cloud）APIキー 3,805件、**DeepSeek 3,170件**、Zhipu 1,489件、**OpenAI 1,348件**など
- **コミット履歴まで調べたため、コードから削除したキーも含まれる**
- 2つのスキャナーの両方が見つけたのは **1,001件だけ**で、結果は大きく違った

**対策のポイント:**
- 一度でも公開したキーは、**発行元で無効化**する（履歴を書き換えても無効にはならない）
- APIキーには**利用できるAPIの制限や利用上限**を設定する
- **シークレットスキャナーは1つに頼らず**、自分が使うサービスに対応しているか確認する
