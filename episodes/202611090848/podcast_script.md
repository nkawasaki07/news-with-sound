### トピック1: Claude APIに「メッセージスレッド」機能がベータで登場
📅 2026年11月2日公開（出典: Claude Platform Docs、Claude Platformリリースノート、Data Studios）

Anthropicは、Messages APIに **Message threads（ベータ）** を追加しました。会話を **サーバー側に一時保持** し、2回目以降は **新しいメッセージだけを送信** できます。

- 最初のリクエストで `thread: {type: "create"}` と system・tools・会話全体を送り、以降は `continue` と直前のレスポンスIDを指定
- ベータヘッダーは `message-threads-2026-08-12`
- 狙いは長いエージェントループでの **最初のトークンが返るまでの時間（TTFT）の短縮と安定化**
- スレッドは **最後のリクエストから5分で期限切れ**、1時間以内に削除。期限切れ時は `thread_not_found` が返るため、会話の正本はアプリ側で保持する
- **料金・レート制限は変わらない**。プロンプトキャッシュは `cache_control` の明示指定が必要
- 追記専用で編集・分岐は不可。Message Batches、トークンカウント、ZDR・HIPAA対象の組織などは非対応

### トピック2: テストフレームワーク「Vitest 5.1」がリリース
📅 2026年11月2日公開（出典: Vitest GitHub Releases、JavaScript Weekly #809）

Vitest 5.1.0が公開され、**必要なテストだけを素早く回す機能** が強化されました。

- **`--since-last-run`**: 前回の実行以降に変更されたテストだけを実行
- **`--last-failed`**: 前回失敗したテストだけを再実行
- **失敗したスナップショットのインタラクティブレビュー** に対応
- フェイクタイマーが `node:timers` / `node:timers/promise` に対応
- `--changed` 使用時に影響を受けたテスト数を総数とあわせて表示
- **ブラウザモードの既定ポートが23315に変更**。固定ポート前提の設定は要確認

### 🔒 トピック3: OpenSSHの認証回避脆弱性「SSHole」（CVE-2026-123158）、公開直後から悪用
📅 2026年11月5日公開（出典: piyolog、Help Net Security、The Hacker News）

**musl libcを使いPAMなしでビルドされたLinux上のOpenSSH sshd** で、パスワードを知らずにログインできる脆弱性が公表されました。代表例は **Alpine Linux** です（CVSS 8.1）。

- 原因: muslの `crypt()` が失敗時に「*」を返し、ロック済みを示すパスワード欄「*」と一致してしまう
- 257〜1024バイトのパスワードで、**パスワード欄が「*」のアカウントに1回の接続でログイン可能**
- 成立条件: PasswordAuthentication有効（既定）、「*」のアカウントが存在、$5$/$6$形式のハッシュを持つアカウントが1つ以上、SSHポートに到達可能
- **修正版はOpenSSH 10.6p2**。Alpineは3.16まで遡って修正パッケージを提供（版番号が据え置きのものがあり、スキャナーが誤検知する可能性）
- Previdianは **公開から9時間未満で攻撃を観測し、ハニーポットでroot侵入を確認**。CISA KEVには記事時点で未掲載
- 対処: 更新後に **sshdの再起動が必要**。更新できない場合は `PasswordAuthentication no` に設定。ログの「Accepted password for」も確認を

### 🔒 トピック4: Android 2026年11月のセキュリティ更新、216件を修正
📅 2026年11月4日公開（出典: 窓の杜、Android Security Bulletin）

Googleは11月2日、Androidの11月セキュリティ情報を公開しました。修正は **216件（Critical 23件、High 193件）** で、前月の25件から大幅に増えています。

- **CVE-2026-58868**: Frameworkのリモートコード実行。**追加権限もユーザー操作も不要** で悪用されるおそれ
- 記事時点で **悪用の報告はなし**

- すべてに対処するには **パッチレベル2026-11-05以降** が必要。対象はAndroid 14〜17
- 配信時期はメーカー次第。開発・検証用端末も早めに更新を
